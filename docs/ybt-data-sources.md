# 一本通题目测试数据来源调研

> 背景：ROJ 补全一本通缺失题目时，测试数据按「先搜刮、搜不到再自产」的原则解决。
> 本文记录 2026-10 的搜刮结果与判定口径。配套工作流见 `scripts/fetch-ybt-statements.py`（题面抓取）与 `.agents/skills/add-roj-problem/SKILL.md`（导入规范）。

## 判定口径

**「有数据」= 机器可直接取用的评测数据**（`git clone` / 直链下载的 `.in/.out` 或打包件）。
需要网盘口令、登录、下载积分的资源（夸克网盘、CSDN 下载）一律记为 **不可用**，回退自产。

## 结论速览

| 书目 | 现成评测数据 | 结论 |
| --- | --- | --- |
| 一本通基础篇（C++语言 / 基础算法 / 数据结构基础） | 部分有 | 参考 `HEEKDragonOne/ACM`（1000–1396），其余沿用 ROJ 自产数据 |
| 一本通提高篇（算法提高篇） | **有** | LibreOJ 官方合作题库（#10000+）的 TestData，可从 GitHub 镜像批量取 |
| 一本通高手训练（高手训练篇） | **无** | 全网只有题解、没有评测数据，全部自产 |

## 详细发现

### 1. 一本通提高篇 —— LibreOJ 官方合作题库（首选）

- LibreOJ 与《信息学奥赛一本通》提高版合作，把书中例题/练习整理为可评测题库，
  题号从 **#10000** 起（如 `#10000 「一本通 1.1 例 1」活动安排` ↔ 一本通 1422）。
  题目名里的「一本通 X.Y 例/练习 Z」编号与本仓库 `problems/` 的题名约定一致，可对齐。
- **GitHub 仓库 `HEEKDragonOne/ACM` 的 `一本通提高版题目和数据/`** 按 LibreOJ 题号归档了
  `TestData_#<loj_id>.zip`（如 `1.贪心/10000/TestData/act0.in…`），可直接 clone 取数。
  该仓库同时有 `一本通基础篇题目和数据/`（1000–1396，`data/problem*.in/.out` + `std.cpp` + `data.py`，
  与本仓库语料同构，可作交叉验证）。
- `w2012974851/ybt-` 声称是「提高篇测试数据」，但只有一个夸克网盘 RAR 链接 —— **不可机取**，忽略。
- LibreOJ 官方 API（`api.loj.ac.cn`）从当前网络环境连接失败，且 loj.ac 页面是 SPA；
  因此取数走 GitHub 镜像，不直连 LOJ。
- **注意**：LOJ 题库只覆盖到「一本通 4.3 练习 3 维护序列」；4.3 练习 4 起
  （如 1992 书架book、1993 开关switch、1994 音乐会）**不在 LOJ**，无现成数据，走自产。

### 2. 一本通高手训练 —— 无现成数据，全部自产

- 全网检索（GitHub / GitCode / CSDN / 博客）只有题解博客与目录贴，**没有可下载的评测数据**。
- 一本通官网（ybt.ssoier.cn/about.php）亦注明：站内数据为站长自产、非官方发放。
- 结论：高手训练篇 149 道缺题全部走自产管线（见下）。

### 3. 其它参考资源（不作为数据源）

| 资源 | 内容 | 为什么不用 |
| --- | --- | --- |
| `SZYInnovationStudio/YBTAnswers` | 全部题面 + 参考解答 | 无评测数据；解答为 AI 生成 |
| `hackwuyue/ybt-problem-crawler` | 抓题面/样例/图片的爬虫 | 可参考思路，不是数据源 |
| `rainboyOJ/problems`（本仓库前身） | 1000–1675 一本通题 + 自产数据 | 数据本体不进 Git，走 BT/HTTP 归档分发 |
| CSDN / GitCode 各类「测试数据下载」 | 零散压缩包 | 需登录/积分，不可机取 |

## 自产规范（无现成数据时）

每个缺题由 herdr 子代理（`pi -ne --no-session`，任务书模板 `.ybt-import/prompts/<pid>.md`）完成：

1. `std.cpp`：C++17 标程，样例必须验证通过；
2. `data.py`：cyaron 生成器，产出 `problem<i>.in/.out`，随机 + 边界数据组合，规模不超题面限制；
3. 难题必须写暴力/慢速参照实现（`work/brute.cpp`）在随机小数据上对拍（≥100 组），参照实现留在暂存区不落地；
4. `gen-report.md`：题意摘要、样例验证、对拍结果、数据设计与风险点；
5. 数据本体不进 Git（`data/` 已在 `.gitignore`），落地后按内部 runbook 打 `tar.zst` 归档上传。

## 已知风险

- 自产数据 ≠ 官方数据，难度分布与极端数据可能不全；对拍能兜底正确性，兜不住数据强度。
- 多解/ Special Judge 类题目（如构造类）自产数据只能保证标程自洽，本地评测按严格比对，需在题面/报告中标注。
- HEEKDragonOne/ACM 的数据未验证权威性（与 LOJ TestData 同名，但无法确认未被修改），重要场合建议与自产结果交叉验证。
