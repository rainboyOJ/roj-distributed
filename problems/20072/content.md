# 整除

给定 $n$ 个数 $a_1,a_2,\ldots,a_n$。

单次操作内，你可以选择 $i\ne j$，并使得 $a_i$ 变为 $a_i-1$，同时 $a_j$ 变为 $a_j+1$。

求最小操作次数，使得，存在整数 $x>1$，满足这 $n$ 个数均能被 $x$ 整除。

注意：任意时刻，你均需要**保证 $a_i$ 非负**。

提示：$0$ 能被任何正整数整除；可以证明，一定有解。

## 输入格式

第一行一个整数 $n$，意义如题述。

第二行 $n$ 个数，表示 $a_1,a_2,\ldots,a_n$。

## 输出格式

仅一行一个数，表示答案。

## 样例

### 输入样例 1

```plain
5
1 2 3 4 5
```

### 输出样例 1

```plain
2
```

### 样例 1 说明

- 初始 $a$ 为 $[1,2,3,4,5]$；
- 第一次，选择 $i=1,j=2$，$a$ 变为 $[0,3,3,4,5]$；
- 第二次，选择 $i=4,j=5$，$a$ 变为 $[0,3,3,3,6]$；
- 此时，取 $x=3$，符合要求。

可以证明，$2$ 是最小的操作次数。

### 输入样例 2

```plain
2
5 7
```

### 输出样例 2

```plain
1
```

### 样例 3

见选手目录下的 $\textit{\textbf{mod/mod3.in}}$ 与 $\textit{\textbf{mod/mod3.ans}}$。

该样例与测试数据 $4\sim 5$ 满足同样的约束条件。

## 数据规模与约定

| 测试点 | 限制 |
|:-:|:-:|
| $1$    | $a_1+a_2+\ldots+a_n$ 为质数 |
| $2\sim3$ | $n\le10$  |
| $4\sim5$    | $n\le10^3$ |
| $6\sim10$    | 无特殊限制 |

对于 $100\%$ 的数据，$2\le n \le 5\times10^5$，$1\le a_i\le 10^5$。
