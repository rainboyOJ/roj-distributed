### 【题目描述】

给定 $N \times M$ 的矩阵 $A$ 和 $M \times K$ 的矩阵 $B$，输出 $C = AB \bmod 998244353$。

### 【输入】

```
$N\ M\ K$
$a_{11}$ $a_{12}$ ... $a_{1M}$
$a_{21}$ $a_{22}$ ... $a_{2M}$
:
$a_{N1}$ $a_{N2}$ ... $a_{NM}$
$b_{11}$ $b_{12}$ ... $b_{1K}$
$b_{21}$ $b_{22}$ ... $b_{2K}$
:
$b_{M1}$ $b_{M2}$ ... $b_{MK}$
```

### 【输出】

```
$c_{11}$ $c_{12}$ ... $c_{1K}$
$c_{21}$ $c_{22}$ ... $c_{2K}$
:
$c_{N1}$ $c_{N2}$ ... $c_{NK}$
```

### 【输入样例】

```
2 2 2
1 1
1 0
5 2
3 1
```

### 【输出样例】

```
8 3
5 2
```

### 【输入样例2】

```
1 2 3
1 2
3 4 5
6 7 8
```

### 【输出样例2】

```
15 18 21
```

### 【输入样例3】

```
1 1 1
123456
789012
```

### 【输出样例3】

```
578563231
```

### 【数据范围】

- $1 \leq N,M,K \leq 1024$
- $0 \leq a_{ij},b_{ij} < 998244353$
