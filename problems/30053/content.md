### 【题目描述】

给定一个长度为 $N$ 的整数序列 $a_0, a_1, \dots, a_{N - 1}$。请按如下方式处理 $Q$ 次查询：

- `0 $l$ $r$ $b$ $c$`：对于每个 $i = l, l+1, \dots, {r - 1}$，令 $a_i \gets a_i+bi+c$。
- `1 $l$ $r$`：输出 $\min_{i \in [l,r)} a_i$。

### 【输入】

```
$N$ $Q$
$a_0$ $a_1$ ... $a_{N - 1}$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
```

### 【输出】

对于每个 `1 l r` 查询，输出一行一个整数，表示区间 $[l,r)$ 中 $a_i$ 的最小值。

### 【输入样例】

```
5 7
1 2 3 4 5
1 0 5
0 2 4 -10 101
1 0 3
0 1 3 12 103
1 2 5
0 2 5 -14 105
1 0 5
```

### 【输出样例】

```
1
1
5
1
```

### 【数据范围】

- $1 \leq N, Q \leq 100000$
- $|a_i| < 1000000000$
- $0 \leq l < r\leq N$
- $|b| < 100$
- $|c| < 10000000$
