# 平均数

average

- 时间限制：1.0 秒
- 内存限制：512 MiB
- 输入输出：标准输入输出

## 题目描述

给定三个正整数 $a, b, c$，每次操作你可以选择其中两个数字，将其中一个增加 1，将另一个减少 1。

问最少需要多少次操作能够使得 $|a + c - 2b|$ 最小，并求出这个最小值。

## 输入格式

第一行一个整数 $T$ 表示数据组数。

接下来 $T$ 行，每行三个正整数 $a, b, c$。

## 输出格式

$T$ 行，每行两个非负整数依次表示最少需要多少次操作能够使得 $|a + c - 2b|$ 最小，以及这个最小值是多少。

## 样例 1 输入

```text
2
1 2 3
1 3 2
```

## 样例 1 输出

```text
0 0
1 0
```

## 样例 1 解释

对 $a = 1, b = 2, c = 3$，显然无需进行任何操作。

对 $a = 1, b = 3, c = 2$，显然通过一次操作变为 $a = 1, b = 2, c = 3$ 即可。

## 数据范围

对 100% 的数据，$1 \le T \le 10^5$，$1 \le a, b, c \le 10^{18}$。

| 测试点编号 | $\max(a, b, c) \le$ | 分值 |
| :---: | :---: | :---: |
| 1 ~ 5 | $3$ | 25 |
| 6 ~ 10 | $10^2$ | 25 |
| 11 ~ 15 | $10^9$ | 25 |
| 16 ~ 20 | $10^{18}$ | 25 |
