### 【题目描述】

给定字符串 $S$ 和 $T$。求 $S$ 与 $T$ 的一个最长公共子串。

### 【输入】

```
$S$
$T$
```

### 【输出】

当最长公共子串可以取为 $(S_a, \ldots, S_{b-1})$ 和 $(T_c, \ldots, T_{d-1})$ 时，输出 $a,b,c,d$。

```
$a$ $b$ $c$ $d$
```

其中，$S_i$ 表示 $S$ 的第 $(1+i)$ 个字符，$T_j$ 表示 $T$ 的第 $(j+1)$ 个字符。

若最长公共子串为空，输出：

```
$0$ $0$ $0$ $0$
```

### 【输入样例】

```
abcdef
abcxdef
```

### 【输出样例】

```
0 3 0 3
```

`3 6 4 7` 也是可接受的答案。

### 【输入样例2】

```
aaa
bbbb
```

### 【输出样例2】

```
0 0 0 0
```

### 【输入样例3】

```
abcabcabc
cabcabcab
```

### 【输出样例3】

```
0 8 1 9
```

### 【输入样例4】

```
aaa
aaaaa
```

### 【输出样例4】

```
0 3 2 5
```

### 【数据范围】

- $1 \leq |S|, |T| \leq 500000$
- $S$、$T$ 的每个字符均为小写英文字母。
