# A. 魔法学院的传送阵

## 题目描述

在艾泽拉魔法学院，有两排平行存在的传送节点：

- 星辉之塔：编号 $1$ 至 $n$
- 月影之塔：编号 $n+1$ 至 $2n$

每座塔的节点之间没有直接通道，但星辉之塔与月影之塔的节点间存在双向魔法传送阵。然而，某些节点间存在元素冲突。每个星辉节点 $i$ 与一个月影节点 $a_i$ 冲突（$n + 1 \le a_i \le 2n$），冲突节点对两两唯一，即所有 $a_i$ 互不相同。

魔法规则：当从节点 $s$ 前往节点 $t$ 时，整条路径禁止同时出现任何冲突节点对。例如：若星辉节点 $1$ 与月影节点 $3$ 冲突，则路径 $1 \to 3 \to 2 \to 4$ 和 $1 \to 4 \to 2 \to 3$ 均为非法路径（同时经过 $1$ 和 $3$），但路径 $1 \to 4$ 合法（未同时出现冲突对）。

魔法导师梅林需要回答学员的旅行咨询：给定起点 $s$ 和终点 $t$，判断是否存在合法路径。如果存在合法路径则输出 `Yes`，否则输出 `No`。

## 输入格式

第一行输入一个整数 $T$，表示测试数据组数。

对于每组测试数据第一行输入两个整数 $n$（节点对数），$s$（起点），$t$（终点）。

第二行输入 $n$ 个整数，表示星辉节点 $i$ 的冲突月影节点 $a_i$。

## 输出格式

对于每一组测试样例，如果存在合法路径输出 `Yes`，否则输出 `No`。

## 样例输入1

```
2
2 1 4
3 4
2 1 4
4 3
```

## 样例输出1

```
Yes
No
```

### 样例解释1

对于第一组数据，可行的一组解为 $1 \to 4$。

## 数据范围

- 对于 $10\%$ 的数据，$1 \le T \le 10$, $n \le 10$，$n + 1 \le a_i \le 2n$。
- 对于 $100\%$ 的数据，$1 \le T \le 10^5$, $1 \le \sum n \le 2 \times 10^5$, $1 \le s, t \le 2n$，$n + 1 \le a_i \le 2n$。
- 数据 **不保证** $s \not= t$。
