### 【题目描述】

给定整数 $N$。请输出 Bernoulli 数 $B_0, B_1, ..., B_N \bmod 998244353$。

### 【输入】

```
$N$
```

### 【输出】

```
$B_0$ $B_1$ ... $B_N
```

### 【输入样例】

```
10
```

### 【输出样例】

```
1 499122176 166374059 0 565671800 0 308980395 0 565671800 0 892369952
```

### 【数据范围】

- $0 \leq N \leq 500,000$
