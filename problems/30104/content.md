### 【题目描述】

给定一张有 $N$ 个顶点、$M$ 条边的简单无向图。第 $i$ 条边为 $(a_i,b_i)$。请将 $G$ 的补图分解为连通块。

### 【输入】

```
$N$ $M$
$a_0$ $b_0$
$a_1$ $b_1$
$\vdots$
$a_{M-1}$ $b_{M-1}$
```

### 【输出】

第一行输出连通块个数 $K$。接下来的 $K$ 行按如下格式输出。其中 $l$ 是一个连通块的顶点数，$v_i$ 是顶点编号。

```
$l$ $v_0$ $v_1$ ... $v_{l-1}$
```

若有多组解，输出其中任意一组即可。

### 【输入样例】

```
4 3
1 0
2 1
1 3
```

### 【输出样例】

```
2
3 0 2 3
1 1
```

### 【输入样例2】

```
6 11
0 1
0 2
0 4
1 2
1 3
1 5
2 3
2 4
2 5
3 4
4 5
```

### 【输出样例2】

```
3
3 0 3 5
2 1 4
1 2
```

### 【输入样例3】

```
5 10
0 1
0 2
0 3
0 4
1 2
1 3
1 4
2 3
2 4
3 4
```

### 【输出样例3】

```
5
1 4
1 3
1 2
1 1
1 0
```

### 【数据范围】

- $1 \leq N \leq 500000$
- $0 \leq M \leq 500000$
- $0 \leq a_i, b_i < N$
- 给定的图是简单图
