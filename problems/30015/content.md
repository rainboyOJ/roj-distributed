### 【题目描述】

给定整数序列 $a_0, a_1, ..., a_{N - 1}$ 和 $b_0, b_1, ..., b_{M - 1}$。按如下方式计算整数序列 $c_0, c_1, ..., c_{(N - 1) + (M - 1)}$：

$$c_k = \sum_{i+j=k} a_i b_j \bmod 1000000007$$

### 【输入】

```
$N$ $M$
$a_0$ $a_1$ ... $a_{N-1}$
$b_0$ $b_1$ ... $b_{M-1}$
```

### 【输出】

```
$c_0$ $c_1$ ... $c_{(N - 1) + (M - 1)}$
```

### 【输入样例】

```
4 5
1 2 3 4
5 6 7 8 9
```

### 【输出样例】

```
5 16 34 60 70 70 59 36
```

### 【输入样例2】

```
1 1
10000000
10000000
```

### 【输出样例2】

```
999300007
```

### 【数据范围】

- $1 \leq N, M \leq 524288$
- $0 \leq a_i, b_i < 1000000007$
