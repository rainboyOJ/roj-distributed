### 【题目描述】

给定多项式 $f(x) = \sum_{i = 0}^{N - 1} a_i x^i \in \mathbb{F} _ {998244353}[x]$。请输出多项式 $g(x) = \sum_{i = 0}^{N} g_i x^i \in \mathbb{F} _ {998244353}[x]$，使得对于任意非负整数 $n$，都有

$$g(n) = \sum_{i = 0}^{n - 1} f(i)$$

### 【输入】

```
$N$
$f_0$ $f_1$ ... $f_{N - 1}$
```

### 【输出】

```
$g_0$ $g_1$ ... $g_N$
```

### 【输入样例】

```
5
1 2 3 4 5
```

### 【输出样例】

```
0 332748118 499122177 665496236 499122175 1
```

### 【输入样例2】

```
2
10000000 10000000
```

### 【输出样例2】

```
0 5000000 5000000
```

### 【数据范围】

- $1 \leq N \leq 524288$
- $0 \leq f_i < 998244353$
