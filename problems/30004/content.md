### 【题目描述】

给定一棵有 $N$ 个顶点的有根树。根为顶点 $0$，顶点 $i$ 的父亲为 $p_i$。请处理 $Q$ 个查询，查询形式如下：

- `$u$ $v$`：输出顶点 $u$ 与 $v$ 的最近公共祖先（LCA）。

### 【输入】

```
$N$ $Q$
$p_1$ $p_2$ ... $p_{N-1}$
$u_0$ $v_0$
$u_1$ $v_1$
:
$u_{Q - 1}$ $v_{Q - 1}$
```

### 【输出】

对每个查询输出一行，表示对应两个顶点的最近公共祖先的编号。

### 【输入样例】

```
5 5
0 0 2 2
0 1
0 4
1 2
2 3
3 4
```

### 【输出样例】

```
0
0
0
2
2
```

### 【数据范围】

- $2 \leq N \leq 500000$
- $1 \leq Q \leq 500000$
- $0 \leq p_i < i$
- $0 \leq u < v \leq N - 1$
