### 【题目描述】

给定一个长度为 $N$ 的字符串 $S$。求 $S$ 的 **不同** 子串的个数。

### 【输入】

```
$S$
```

### 【输出】

```
$ans$
```

### 【输入样例】

```
abcbcba
```

### 【输出样例】

```
21
```

### 【输入样例2】

```
mississippi
```

### 【输出样例2】

```
53
```

### 【输入样例3】

```
ababacaca
```

### 【输出样例3】

```
33
```

### 【输入样例4】

```
aaaaa
```

### 【输出样例4】

```
5
```

### 【数据范围】

- $1 \leq N \leq 500,000$
- $S$ 的每个字符均为小写英文字母。
