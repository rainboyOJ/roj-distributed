# 天

(sky.cpp 1s/512MB)

## 题目描述

一天，小 Y 正在做 CSP-J 模拟赛。模拟赛第一题的题意如下：

> 给定一个只包含 $0$ 或 $1$ 的字符串 $s$，将所有左边是 `00` 的 $1$ 都变为 $0$，输出得到的字符串 $s'$。

小 Y 自然是熟练地写出了代码，就在她打开样例文件准备测试样例时，她旁边的同学却告诉他样例文件被动了手脚，文件里有些 $0$ 变成了 $1$，也有一些 $1$ 变成了 $0$。不过好在就算输入或输出字符串的某些位置被修改，这仍然可能是一组合法的样例。现在，给你被动了手脚之后的输入 $s$ 和输出 $s'$，你能告诉小 Y 这是否是一组合法的样例吗？

## 输入格式

第一行包含一个整数 $n$，表示字符串长度。

第二行包含一个仅由字符 `0` 和 `1` 组成的字符串 $s$，长度为 $n$。

第三行包含一个仅由字符 `0` 和 `1` 组成的字符串 $s'$，长度为 $n$。

## 输出格式

若给定的 $(s,s')$ 符合上述生成规则，输出 `YES`；否则输出 `NO`。

## 输入输出样例 #1

### 输入 #1

```
5
00011
00001
```

### 输出 #1

```
YES
```

## 输入输出样例 #2

### 输入 #2

```
5
01000
00000
```

### 输出 #2

```
NO
```

## 数据范围

对于 $30\%$ 的数据，$n=2$。

对于 $100\%$ 的数据，$n\le 10^5$。
