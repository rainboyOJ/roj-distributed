### 【题目描述】

给定一个 $N \times M$ 的矩阵 $A = \lbrace a_{ij} \rbrace$，其元素取自 $\mathbb{Z}/2\mathbb{Z}$，输出矩阵 $A$ 的秩。

在输入矩阵时，请把每一行看作由它的各个分量（$0$ 或 $1$）拼接而成的字符串。

### 【输入】

```
$N$ $M$
$a _ {11} \cdots a _ {1M}$
$\vdots$
$a _ {N1} \cdots a _ {NM}$
```

### 【输出】

输出矩阵 $A$ 的秩。

### 【输入样例】

```
3 3
110
101
011
```

### 【输出样例】

```
2
```

### 【输入样例2】

```
1 1
0
```

### 【输出样例2】

```
0
```

### 【输入样例3】

```
2 0


```

### 【输出样例3】

```
0
```

### 【数据范围】

- $0 \leq N, M \leq 16777216$
- $0 \leq NM \leq 16777216$
- $0 \leq a_{ij} < 2$
