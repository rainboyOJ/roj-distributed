### 【题目描述】

整数序列 $(a_i)$ 满足如下线性递推：

$$a_{i} \equiv \sum_{j=1}^{d} c_j a_{i - j} \pmod{998244353},\  i\geq d$$

给定 $a_0,a_1,\ldots,a_{d-1}$，对 $i=0,1,\ldots,M-1$ 输出 $a _ {k + i} \bmod 998244353$。

### 【输入】

```
$d$ $k$ $M$
$a_0$ $a_1$ $\ldots$ $a_{d-1}$
$c_1$ $c_2$ $\ldots$ $c_d$
```

### 【输出】

```
$a_k$ $a_{k+1}$ $\cdots$ $a_{k+M-1}$
```

### 【输入样例】

```
2 5 10
1 1
1 1
```

### 【输出样例】

```
8 13 21 34 55 89 144 233 377 610
```

### 【输入样例2】

```
2 1 4
1 1
0 0
```

### 【输出样例2】

```
1 0 0 0
```

### 【输入样例3】

```
4 0 7
1 2 3 4
1 1 0 0
```

### 【输出样例3】

```
1 2 3 4 7 11 18
```

### 【数据范围】

- $1 \leq d \leq 100000$
- $0 \leq k \leq 1000000000000000000$
- $1 \leq M \leq 500000$
- $0 \leq a_i \lt 998244353\ (0 \leq i \leq d-1)$
- $0 \leq c_i \lt 998244353\ (1 \leq i \leq d)$
