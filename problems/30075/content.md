### 【题目描述】

设 $a_k$ 为大小为 $k$ 的满足对于每个 $i$ 都有 $p_i \neq i$ 的排列 $p$ 的数量。

给定 $N, M$。对于每个 $i = 1, \cdots, N$，输出 $b_k = a_k \bmod M$。

### 【输入】

```
$N$ $M$
```

### 【输出】

```
$b_1$ $b_2$ $\ldots$ $b_N$
```

### 【输入样例】

```
10 100
```

### 【输出样例】

```
 0 1 2 9 44 65 54 33 96 61
```

### 【输入样例2】

```
20 998244353
```

### 【输出样例2】

```
 0 1 2 9 44 265 1854 14833 133496 1334961 14684570 176214841 294304226 127281753 910981941 600290115 222488424 11814221 224470198 496426549
```

### 【数据范围】

- $1 \leq N \leq 10^6$
- $1 \leq M \leq 10^9$
