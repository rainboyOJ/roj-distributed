# 消息传递

题目描述
一共有𝑛𝑛个人，第𝑖𝑖个有一个消息𝑖𝑖，所有的消息都是不同的。某两个人之间能互相
传递消息，这样互相传递的关系形成了一棵树。

每一轮，都会有一个人，把他现在知道的所有消息传递给相邻的另一个人。问最少
多少轮之后，所有人都知道所有的消息。在最小轮数的条件下，会有多少种不同的
传递消息的方法。两种方法不同，当且仅当存在某一轮，发消息或者收消息的人不
同。

输入格式
第一行，一个整数𝑛𝑛。

接下来𝑛𝑛 − 1，每行两个整数，表示两个有传递关系的人。

输出格式
一行，一个整数表示传递的方法，答案对109 + 7取模。这里并不需要输出最小的
轮数。

样例输入 1
3
1 2
2 3

样例输出 1
6

样例解释
一个可行的方法是，3 → 2,2 → 1,1 → 2,2 → 3。

样例输入输出 2
见下发文件。

数据规模
共 10 组数据。

测试点1满足𝑛𝑛 ≤ 5。

测试点2满足𝑛𝑛 ≤ 10。

测试点3,4,5满足𝑛𝑛 ≤ 2000。

测试点6,7满足传递关系是一条链。
对于所有数据，满足1 ≤ 𝑛𝑛 ≤ 2 × 105 。
