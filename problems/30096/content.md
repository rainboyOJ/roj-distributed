### 【题目描述】

本题包含 $T$ 组测试数据。

给定 $N$ 个二维点 $(x_i,y_i)$（$0\leq i\leq N-1$），令 $P$ 为这些点的凸包。请按逆时针顺序输出 $P$ 的顶点坐标。

更详细的定义请参见下面的注释。

注释：

- 对于二维点的一个（多重）集合 $S$，将 $S$ 的凸包记为 $\mathrm{conv}(S)$。
- 定义 $P=\mathrm{conv}(\lbrace (x_i,y_i)\mid 0\leq i\leq N-1\rbrace)$。
- 可以证明，存在满足 $\mathrm{conv}(S')=P$ 的最小集合 $S'$。$P$ 的顶点定义为 $S'$ 中的元素。
- 当 $|S'|\leq 2$ 时，以任意顺序输出 $S'$ 中的点。当 $|S'|\geq 3$ 时，可以证明 $P$ 是一个凸多边形，$S'$ 是其顶点，并且可以定义其逆时针顺序。可以旋转这个顺序，若输出的顺序为逆时针方向则均可接受。
- 根据上述定义，如果点 $S$ 在 $P$ 的一条边上但不是顶点，则不应输出该点。
- 输入中可能包含坐标相同的多个点，但输出中不应包含坐标相同的多个点。

### 【输入】

输入格式如下：

```
$T$
$N$
$x_0$ $y_0$
$x_1$ $y_1$
:
$x_{N - 1}$ $y_{N - 1}$
$N$
$x_0$ $y_0$
$x_1$ $y_1$
:
$x_{N - 1}$ $y_{N - 1}$
$\vdots$
```

### 【输出】

对于每组测试数据，按照以下格式输出坐标：

```
$M$
$x'_0$ $y'_0$
$x'_1$ $y'_1$
:
$x'_{M - 1}$ $y'_{M - 1}$
```

```

```

### 【输出样例】

```

2 0
2 2
0 2
```


### 【数据范围】

- $1\leq T\leq 10^5$
- $0\leq N\leq 500000$
- $|x_i|,|y_i|\leq 1000000000$
- $x_i,y_i$ 为整数。
- 所有测试数据中 $N$ 的总和不超过 $500000$
