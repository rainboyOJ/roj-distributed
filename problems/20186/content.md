# 和平精英

### 题目信息

时间限制:  `1s`

空间限制: `256M`

输入文件: `peace.in`

输出文件: `peace.out`

### 题目描述

T 国议会由 $n$ 位议员组成，第 $i$ 位议员的影响力为 $a_i$。T 国最大的两个执政党分别是与党和或党，对于某个议员序列 $[b_1, b_2, \dots, b_m]$，其中 $b_i$ 表示议员 $i$ 的影响力，若可以将这个序列中的每位议员分配给与党或或党，使得与党议员集合中的议员们的影响力按位与的结果等于或党议员集合中的议员们的影响力按位或的结果，那么就能避免与党和或党的冲突。

例如议员序列 $[1, 7, 3, 11]$，可以将 $[1, 7]$ 划分给与党，影响力按位与的结果为 3，将 $[3, 11]$ 划分给或党，影响力按位或的结果也为 3，因此这个序列可以避免与党或党的冲突。

现在给出 $Q$ 组询问, 每组询问形如 $l_i, r_i$, 你需要回答 $\left[a_l, a_{l+1}, \ldots, a_r\right]$ 这个议员序列能否避免与党或党的冲突。

### 输入格式

第一行两个正整数 $n, Q\left(1 \leq n, Q \leq 10^5\right)$

第二行一个长度为 $n$ 的序列 $a_1, a_2, \ldots, a_n\left(0 \leq a_i<2^{30}\right)$

然后 $Q$ 行每行两个正整数 $l, r(1 \leq l, r \leq n)$，表示一组询问。

### 输出格式

输出 $Q$ 行，每行一个字符串：
+ 若可以避免冲突，输出 `YES`
+ 若无法避免冲突，输出 `NO`
