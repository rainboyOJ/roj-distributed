### 【题目描述】

本题中 $i$ 表示虚数单位。

给定高斯整数 $a_1+b_1i$ 和 $a_2+b_2i$，求它们的一个最大公约数。

高斯整数及其最大公约数的定义如下：

- $\mathbb{Z}[i] = \lbrace a+bi\mid a,b\in \mathbb{Z}\rbrace$ 中的元素称为高斯整数。

- 对于 $x, y \in \mathbb{Z}[i]$，若存在 $\mathbb{Z}[i]$ 中的 $z$ 使得 $y = xz$，则定义 $x\mid y$。

- 高斯整数 $g$ 是 $x, y\in \mathbb{Z}[i]$ 的最大公约数，当且仅当对任意 $\mathbb{Z}[i]$ 中的 $z$，条件 $z\mid g$ 与「$z\mid x$ 且 $z\mid y$」等价。这样的 $g$ 在相差 $\pm 1$ 和 $\pm i$ 的倍数意义下唯一确定。

你需要解决 $T$ 组测试数据。

### 【输入】

```
$T$
$a_1$ $b_1$ $a_2$ $b_2$
$\vdots$
$a_1$ $b_1$ $a_2$ $b_2$
```

### 【输出】

若 $a+bi$ 是 $a_1+b_1i$ 和 $a_2+b_2i$ 的一个最大公约数，则输出 $a$ 和 $b$。

```
$a$ $b$
```

### 【输入样例】

```
8
8 0 6 0
0 0 0 0
0 0 4 8
4 0 6 2
1 2 3 4
1 -2 3 4
1 -3 5 -7
-344235 225420 -33882 162741
```

### 【输出样例】

```
2 0
0 0
4 8
-2 -2
1 0
1 -2
-1 1
-456 123
```

对于第一组测试数据，除 `2 0` 外，`-2 0`、`0 2`、`0 -2` 也是正确答案。

### 【数据范围】

- $1 \leq T \leq 100000$
- $-1000000000 \leq a_1, b_1, a_2, b_2 \leq 1000000000$
