### 【题目描述】

给定 $N \times N$ 的矩阵 $M = \lbrace a_{ij} \rbrace$。输出其（首一的）特征多项式 $p(x)$，其中

$$p(x) = \det (xI - M) = \sum_{i = 0}^N p_i x^i$$

$I$ 表示 $N \times N$ 的单位矩阵。$0 \times 0$ 矩阵的行列式等于 $1$。所有运算均在 $\mathbb{Z}/998244353\mathbb{Z}$ 下进行。

### 【输入】

```
$N$
$a_{11}$ $a_{12}$ ... $a_{1N}$
$a_{21}$ $a_{22}$ ... $a_{2N}$
:
$a_{N1}$ $a_{N2}$ ... $a_{NN}$
```

### 【输出】

```
$p_0$ $p_1$ ... $p_N$
```

### 【输入样例】

```
0
```

### 【输出样例】

```
1
```

### 【输入样例2】

```
1
1
```

### 【输出样例2】

```
998244352 1
```

### 【输入样例3】

```
2
1 2
3 4
```

### 【输出样例3】

```
998244351 998244348 1
```

### 【数据范围】

- $0 \leq N \leq 500$
- $0 \leq a_{ij} < 998244353$
