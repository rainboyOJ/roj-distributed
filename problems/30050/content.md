### 【题目描述】

给定一个大小为 $N$ 的整数序列 $a_0, a_1, \dots, a_{N - 1}$。初始时对所有 $i$ 都有 $a_i = 0$。
请依次处理 $Q$ 个查询：

- `0 $l$ $r$ $b$ $c$`：对每个 $i = l, l+1, \dots, {r - 1}$，执行 $a_i \gets b \times a_i + c$。
- `1 $l$ $r$`：输出 $\sum_{i = l}^{r - 1} a_i \bmod 998244353$。

### 【输入】

```
$N$ $Q$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
```

### 【输出】

对每个 `1 $l$ $r$` 查询，输出一行一个整数，表示 $\sum_{i = l}^{r - 1} a_i \bmod 998244353$。

### 【输入样例】

```
1000000000 6
0 0 100 10 1
1 10 90
1 0 1000000000
0 50 10000 10 1
1 10 90
1 0 1000000000
```

### 【输出样例】

```
80
100
480
10500
```

### 【数据范围】

- $1 \leq N \leq 1000000000$
- $1 \leq Q \leq 100000$
- $0 \leq l < r \leq N$
- $1 \leq b < 998244353$
- $0 \leq c < 998244353$
