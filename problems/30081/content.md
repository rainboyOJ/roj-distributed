### 【题目描述】

带符号的第一类斯特林数 $s(n, k)$ 定义为如下恒等式中的系数：

$$x (x - 1) \cdots (x - (n - 1)) = \sum_{k=0}^n s(n, k) x^k.$$

给定一个整数 $N$，请对 $0 \le k \le N$ 计算 $s(N, k) \bmod 998244353$。

### 【输入】

输入包含一个整数 $N$。

```
$N$
```

### 【输出】

输出 $s(N, 0),\ \cdots,\ s(N, N)$。

```
$s(N, 0)$ $\cdots$ $s(N, N)$
```

### 【输入样例】

```
5
```

### 【输出样例】

```
0 24 998244303 35 998244343 1
```

### 【数据范围】

- $0 \le N \le 500000$
