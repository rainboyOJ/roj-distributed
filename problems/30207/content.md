### 【题目描述】

给定一个形式幂级数 $f(x) = \sum_{i=0}^{N-1} a_i x^i \in \mathbb{F}\_{998244353}[[x]]$ 以及一个非负整数 $M$。
计算 $(f(x))^M = \sum_{i=0}^{\infty} b_i x^i$ 的前 $N$ 项。

### 【输入】

```
$N$ $M$
$a_0$ $a_1$ $\cdots$ $a_{N-1}$
```

### 【输出】

```
$b_0$ $b_1$ $\cdots$ $b_{N - 1}$
```

### 【输入样例】

```
4 3
0 0 9 12
```

### 【输出样例】

```
0 0 0 0
```

### 【输入样例2】

```
2 2
1 1
```

### 【输出样例2】

```
1 2
```

### 【输入样例3】

```
2 0
0 0
```

### 【输出样例3】

```
1 0
```

### 【数据范围】

- $1 \leq N \leq 500000$
- $0 \leq M \leq 1000000000000000000$
- $0 \leq a_i < 998244353$
