# A. 自动化生产

## 题目描述

某玩具厂启动了一条自动化生产线。生产主管设定了三台机器的循环作业模式：

- 周期第 $1$ 天：机器 $A$ 产出 $a$ 个零件
- 周期第 $2$ 天：机器 $B$ 产出 $b$ 个零件
- 周期第 $3$ 天：机器 $C$ 产出 $c$ 个零件
- 周期第 $4$ 天：机器 $A$ 再次产出 $a$ 个零件
- 周期第 $5$ 天：机器 $B$ 再次产出 $b$ 个零件
- 周期第 $6$ 天：机器 $C$ 再次产出 $c$ 个零件

依此循环往复。

当累计零件产量至少达到 $n$ 个时，生产线将立即停工。请确定生产持续的总天数。

## 输入格式

第一行包含一个正整数 $T$ 表示测试样例数量。

每一个测试样例由一行四个整数 $n$, $a$, $b$, $c$ 组成。

## 输出格式

对于每一组测试样例，输出一行一个整数，表示生产持续的总天数。

## 样例输入1

```
4
12 1 5 3
6 6 7 4
```

## 样例输出1

```
5
1
```

## 样例解释

- 在第一组测试样例中，机器日产量 $a = 1$, $b = 5$, $c = 3$，目标生产零件 $n = 12$。第一天累计生产 $1 < 12$，第二天累计生产 $1 + 5 = 6 < 12$，第三天累计生产 $6 + 3 < 9$，第五天累计生产 $10 < 12$，第五天累计 $15 \ge 12$，所以生产线将在第五天停工。
- 在第二组测试样例中，机器日产量 $a = 6$，$b = 7$，$c = 4$，目标生产零件 $n = 6$。第一天累计生产 $6 \le 6$，第1天即达目标，所以生产线将在第1天停工。

## 数据范围

- 对于 $10\%$ 的数据，$1 \le T \le 10$, $n \le 10$。
- 对于 $50\%$ 的数据，$\sum n \le 10^6$。
- 对于 $100\%$ 的数据，$1 \le T \le 10^4$, $1 \le n \le 10^9$, $1 \le a, b, c \le 10^6$。
