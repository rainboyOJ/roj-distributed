### 题目描述

在一场大型知识竞答大会结束后，主办方准备为表现优异的参赛者颁发荣誉勋章。

- “星辰勋章”将授予得分最高的所有参赛者（可能有多个）。
- “曙光勋章”将授予得分第二高的所有参赛者（可能有多个）。
- “流光勋章”将授予得分第三高的所有参赛者（可能有多个）。

你收到了一份包含所有参赛者得分的名单，请你找出获得“流光勋章”所需的分数是多少，以及有多少人正好得到了这个分数。

### 输入格式

第一行包含一个整数 $N$，表示参赛者的人数。

接下来的 $N$ 行，每行一个整数，表示一位参赛者的得分。

保证所有分数在 $0$ 到 $75$ 之间（含），并且至少存在三种不同的分数。

### 输出格式

输出一行，包含两个整数 $S$ 和 $P$，用空格分隔：

- $S$ 表示获得“流光勋章”所需的分数，
- $P$ 表示有多少人正好得到了这个分数。

### 数据范围

对于 40% 的数据，$N\leq 50$ ，且分数互不相同。

对于另外 30% 的数据，$N\leq 50$ 。

对于 100% 的数据，$1\leq N\leq 2.5\times 10^5$ ，分数 $s$ 满足 $0\leq s\leq 75$ ，至少存在 3 个不同分数。

### 输入输出样例

#### 输入样例1

```
4
70
62
58
73
```

#### 输出样例1

```
62 1
```

#### 输入样例2

```
8
75
70
60
70
70
60

```

#### 输出样例2

```

```
