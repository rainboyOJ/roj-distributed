### 【题目描述】

给定一个长度为 $N$ 的整数序列 $a_0, a_1, ..., a_{N-1}$。

依次处理以下 $Q$ 个查询：

- `0 $p$ $x$`：$a_p \gets x$
- `1 $l$ $r$`：输出 $(a_l, a_{l+1}, ..., a_{r-1})$ 中的多数元素。若不存在多数元素，输出 $-1$。

### 【输入】

```
$N$ $Q$
$a_0$ $a_1$ ... $a_{N-1}$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q-1}$
```

### 【输出】

对每个 `1 $l$ $r$` 查询，输出一行一个整数，表示 $(a_l, a_{l+1}, ..., a_{r-1})$ 中的多数元素；若不存在多数元素，输出 $-1$。

### 【输入样例】

```
7 4
1 5 5 2 4 3 2
1 1 4
1 3 7
0 5 2
1 3 7
```

### 【输出样例】

```
5
-1
2
```

### 【数据范围】

- $1 \leq N \leq 500000$
- $1 \leq Q \leq 500000$
- $0 \leq a_i \leq 1000000000$
- $0 \leq p < N$
- $0 \leq x \leq 1000000000$
- $0 \leq l < r \leq N$
