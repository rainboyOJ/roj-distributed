### 【题目描述】

给定一个带权无向图，图中有 $N$ 个顶点和 $M$ 条边。第 $i$ 条边为 $(a_i, b_i)$，权值为 $c_i$。这个图可能不是简单图。

请找出一棵直径最小的生成树。

### 【输入】

第一行包含两个整数 $N$ 和 $M$。

接下来 $M$ 行，第 $i$ 行包含三个整数 $a_i$、$b_i$ 和 $c_i$，表示一条连接顶点 $a_i$ 和 $b_i$、权值为 $c_i$ 的边。

```text
$N$ $M$
$a_0$ $b_0$ $c_0$
$a_1$ $b_1$ $c_1$
:
$a_{M - 1}$ $b_{M - 1}$ $c_{M - 1}$
```

### 【输出】

输出两行。

```text
$X$
$e_0$ $e_1$ $e_2$ ... $e_{N - 2}$
```

第一行输出 $X$。

第二行输出 $e_0$、$e_1$、$e_2$、……、$e_{N-2}$。

$X$ 是直径最小的生成树的直径。$e_i$ 是直径最小的生成树中边的编号。
如果有多个正确答案，输出任意一个即可。

### 【输入样例】

```
4 7
0 1 1
0 1 2
1 1 0
0 2 2
1 2 2
0 3 1
2 3 3
```

### 【输出样例】

```
3
0 5 3 
```

### 【输入样例2】

```
4 3
0 1 1
1 2 2
3 1 3
```

### 【输出样例2】

```
5
0 1 2 
```

### 【输入样例3】

```
6 5
0 1 1000000000
1 2 1000000000
2 3 1000000000
3 4 1000000000
4 5 1000000000
```

### 【输出样例3】

```
5000000000
0 1 3 4 2 
```

### 【输入样例4】

```
1 0
```

### 【输出样例4】

```
0
```

### 【数据范围】

- $1 \leq N \leq 2000$
- $N - 1 \leq M \leq 2000$
- $0 \leq a_i, b_i < N$
- $0 \leq c_i \leq 1000000000$
- 给定的图是连通的。
