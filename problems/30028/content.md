### 【题目描述】

给定一个无限长的数组 $a$，初始时所有元素均为 $0$。依次处理以下 $Q$ 个查询。

- `0 $k$ $v$`：$a[k] \gets v$
- `1 $k$`：输出 $a[k]$

### 【输入】

```
$Q$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
```

### 【输出】

对每个 `1 k` 查询输出一行，为对应的 $a[k]$ 的值。

### 【输入样例】

```
8
0 1 2
1 1
1 2
0 2 3
1 1
1 2
0 2 1
1 2
```

### 【输出样例】

```
2
0
2
3
1
```

### 【数据范围】

- $1 \leq Q \leq 1000000$
- $0 \leq k, v \leq 1000000000000000000$
