### 【题目描述】

给定整数 $A$ 和 $B$，输出 $A + B$。

### 【输入】

```
$A$ $B$
```

### 【输出】

```
$A + B$
```

### 【输入样例】

```
1234 5678
```

### 【输出样例】

```
6912
```

### 【输入样例2】

```
1000000000 1000000000
```

### 【输出样例2】

```
2000000000
```

### 【数据范围】

- $0 \leq A, B \leq 1000000000$
