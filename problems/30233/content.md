### 【题目描述】

给定一个由互不相同的整数组成的序列 $A = (a_0, a_1, \dots, a _ {N-1})$。
构造由该序列 $A$ 得到的笛卡尔树。
最小的元素成为根。

### 【输入】

```
$N$
$a_0$ $a_1$ ... $a _ {N - 1}$
```

### 【输出】

```
$p_0$ $p_1$ $p_2$ ... $p_{N - 1}$
```

$p_i$ 是顶点 $i$ 的父亲。对于树的根节点 $r$，$p_r = r$。

### 【输入样例】

```
3
1 0 2
```

### 【输出样例】

```
1 1 1
```

### 【输入样例2】

```
11
9 3 7 1 8 12 10 20 15 18 5
```

### 【输出样例2】

```
1 3 1 3 10 6 4 8 6 8 3
```

### 【数据范围】

- $1 \leq N \leq 1000000$
- $0 \leq a_i \leq 1000000000$
- $i \ne j$ 蕴涵 $a_i \ne a_j$
- 所有值均为整数
