# 唬牌游戏

#### 题目描述
近些天，一款名为唬牌的游戏风靡全校，游戏规则如下：

所需游戏道具是若干张扑克牌，此时每张牌都具有一个花色。

一共两名玩家参赛，游戏共两局。在第一局游戏的每个回合中，玩家 A 将若干张**相同花色**的扑克牌扣置（此时玩家 B **不知道** 玩家 A 扣置的是什么花色），并声称一种花色，玩家 B 则需要猜测玩家A所扣置的牌是否与其声称花色相同，猜对则 B 得一分。无论B是否猜对，A 都要告诉 B 自己扣置的牌是否与声称花色相同，**并且将扣置的牌放入弃牌堆**（B看不见这些牌的花色是什么，只知道这些牌花色是否与声称花色相同）。第二局游戏玩家 A 与玩家 B 的角色互换。最终谁的得分更高，谁获得比赛胜利。

现在 zzy 和 zsh 正在进行唬牌对决，游戏已经进行到了白热化的阶段，而 zzy 需要你的帮助。

你已经知道前 $n$ 回合的所有信息，请你帮助 zzy 做出这一回合的判断，是 zsh 的声称一定正确，还是一定错误，还是你也不清楚，表示无能为力？

zzy 预想了 $m$ 种 zsh 在第 $n+1$ 回合可能会进行的操作，你需要对其一一解答。

为了方便你的输入，我们使用字符 $D$ 代表方片，字符 $C$ 代表草花，字符 $H$ 代表红桃，字符 $S$ 代表黑桃。
#### 输入格式

第一行四个整数 $a,b,c,d$ 代表扑克牌中方片、草花、红桃、黑桃牌的张数。

第二行输入一个整数 $n$。

接下来 $n$ 行每行输入 一个字符，表示声称的花色；一个数字，表示扣置牌数；一个字符 $T$ 或 $F$ 表示扣置牌与 zsh 声称牌花色是否一致。

接下来一行输入一个整数 $m$。

接下来 $m$ 行，每行输入一个字符和一个数字，表示 zzy 预想本回合 zsh 可能进行的声称。字符表示花色，数字表示扣置牌数，

#### 输出格式

输出共 $m$ 行 ，每行一个字符串，表示如果 zsh 这么声称，你的回答是什么。一定正确输出 $T$, 一定错误输出 $F$, 你也不清楚输出 $NG$
特别的，如果 zsh 根本不可能进行这样的声称，输出 $ERROR$

#### 样例输入 #1

```
1 1 1 1
2
D 1 T
D 1 F
3
D 1
H 1
H 2
```

#### 样例输出 #1
```
F
NG
ERROR
```

#### 样例输入 #2

```
10 10 10 10
10 
D 5 T
C 5 T
H 5 T
S 5 T
C 3 T
S 3 T
H 3 T
D 1 F
D 1 F
S 1 F
1
D 5
D 6

```
#### 样例输出 #2
```
T
ERROR
```

#### 样例解释 #2
```
D 花色最多剩五张，其余花色最多剩两张，
因为每次扣置牌花色必须一样，所以如果 zsh 声称 D 5，那么一定是 D 花色
zsh不存在有一个花色剩余大于五张，所以他下回合不可能声称 D 6
```
#### 数据范围与约定

对于所有数据，有：

-  $0 < n,m,a,b,c,d \le 80$

| 测试点编号  |  数据限制   | 特殊性质 |
| :---------: | :---------: |:---------: |
| $1 \sim 2$  |  $n,m,a,b,c,d \le 10$  | |
| $3 \sim 4$  | $n,m,a,b,c,d \le 30$  ||
| $5 \sim 6$  | 无  |A|
| $7 \sim 10$ | 无 |  |

特殊性质 A: 前 n 回合 zsh 所扣置的牌和其声称的牌花色均相同
