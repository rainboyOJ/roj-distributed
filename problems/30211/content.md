### 【题目描述】

给定次数小于 $N$ 的多项式 $f(x) \in \mathbb{F}_{998244353}[x]$ 的采样点 $f(0), f(1), \ldots , f(N - 1)$，请计算 $f(c ＋ i)$，其中 $i = 0, 1, \ldots , M - 1$。

### 【输入】

```
$N$ $M$ $c$
$f(0)$ $f(1)$ ... $f(N - 1)$
```

### 【输出】

```
$f(c)$ $f(c + 1)$ ... $f(c + M - 1)$
```

### 【输入样例】

```
4 5 3
1 4 9 16
```

### 【输出样例】

```
16 25 36 49 64
```

### 【输入样例2】

```
4 5 998244349
1 8 27 64
```

### 【输出样例2】

```
998244326 998244345 998244352 0 1
```

### 【数据范围】

- $1 \leq N,M \leq 524288$
- $0 \leq c, f(i) < 998244353$
