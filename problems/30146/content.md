### 【题目描述】

给定 $N \times M$ 的矩阵 $A$，请求出 $A$ 的秩。所有运算均在 $\mathbb{F}_{998244353}$ 上进行。

### 【输入】

```
$N$ $M$
$A_{0,0}$ $A_{0,1}$ ... $A_{0,M-1}$
$A_{1,0}$ $A_{1,1}$ ... $A_{1,M-1}$
:
$A_{N-1,0}$ $A_{N-1,1}$ ... $A_{N-1,M-1}$
```

### 【输出】

输出 $A$ 的秩。

### 【输入样例】

```
3 3
1 2 3
4 5 6
7 8 9
```

### 【输出样例】

```
2
```

### 【输入样例2】

```
1 5
1 2 3 4 5
```

### 【输出样例2】

```
1
```

### 【输入样例3】

```
2 2
0 0
0 0
```

### 【输出样例3】

```
0
```

### 【输入样例4】

```
3 0



```

### 【输出样例4】

```
0
```

### 【数据范围】

- $0 \leq N, M \leq 250000$
- $NM\leq 250000$
- $0 \leq A_{ij} < 998244353$

### 【来源】

Library Checker（yosupo06） matrix_rank
