### 【题目描述】

给定二维平面上的 $N$ 个带权点组成的初始多重集合 $P = (P_0, P_1, \dots, P_{N - 1})$。每个点 $P_i$（$0 \leq i < N$）位于 $(x_i, y_i)$，并具有权值 $w_i$。请处理 $Q$ 个如下类型的查询。对于第 $i$ 个（$0\leq i < Q$）查询：

- `0 $x$ $y$ $w$`：在坐标 $(x, y)$ 处添加一个权值为 $w$ 的新点。设添加前 $|P| = k$，则将该点记为 $P_k$。如果这些坐标处已经存在点，则将新点作为一个独立的实例添加。
- `1 $x$ $w$`：将点 $P_x$ 的权值更新为 $w$（即 $w_x \gets w$）。
- `2 $l$ $d$ $r$ $u$`：求满足 $l \leq x_i < r$ 且 $d \leq y_i < u$ 的所有点的权值之和，结果对 $998244353$ 取模。
- `3 $l$ $d$ $r$ $u$ $a$ $b$`：对于所有满足 $l \leq x_i < r$ 且 $d \leq y_i < u$ 的 $i$，执行变换 $w_i \gets a \cdot w_i + b$。

### 【输入】

输入格式如下：

```
$N$ $Q$
$x_0$ $y_0$ $w_0$
$x_1$ $y_1$ $w_1$
$x_2$ $y_2$ $w_2$
$\hspace{17pt} \vdots$
$x_{N - 1}$ $y_{N - 1}$ $w_{N - 1}$
$\mathrm{Query}_0$
$\mathrm{Query}_1$
$\mathrm{Query}_2$
$\hspace{13pt} \vdots$
$\mathrm{Query}_{Q - 1}$
```

### 【输出】

对于每个类型为 `2` 的查询，输出一行一个整数，表示满足条件的所有点的权值之和对 $998244353$ 取模后的结果。

### 【输入样例】

```
3 7
2 0 1
6 2 10
5 4 100
2 1 1 7 7
0 5 6 1000
0 5 1 10000
3 1 5 7 7 0 100000
1 1 1000000
2 5 4 7 5
2 5 1 7 7
```

### 【输出样例】

```
110
100
1110100
```

### 【数据范围】

- $1 \leq N \leq 100000$
- $1 \leq Q \leq 100000$
- $0 \leq x_i, y_i \leq 1000000000$
- $0 \leq w_i < 998244353$

对于每种查询类型：

- 类型 `0`：$0 \leq x, y \leq 1000000000$，$0 \leq w < 998244353$
- 类型 `1`：$0\leq x < |P|$，$0\leq w < 998244353$
- 类型 `2`：$0 \leq l < r \leq 1000000000$，$0 \leq d < u \leq 1000000000$
- 类型 `3`：$0 \leq l < r \leq 1000000000$，$0 \leq d < u \leq 1000000000$，$0 \leq a, b < 998244353$
