### 【题目描述】

共有 $T$ 组数据。
每组数据给定整数 $A$ 和 $B$，输出 $A + B$。

### 【输入】

```
$T$
$A$ $B$
 $\vdots$
$A$ $B$
```

### 【输出】

```
$A + B$
 $\vdots$
$A + B$
```

### 【输入样例】

```
3
1 2
11 22
1000000000000000000 1000000000000000000
```

### 【输出样例】

```
3
33
2000000000000000000
```

### 【数据范围】

- $1 \leq T \leq 1000000$
- $0 \leq A, B \leq 1000000000000000000$
