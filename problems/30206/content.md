### 【题目描述】

给定一个多项式 $f(x) = \sum_{i=0}^{N-1} a_ix^i \in \mathbb{Z}[x]$ 和一个整数 $c$。
请计算满足 $f(x+c) = \sum_{i=0}^{N-1}b_ix^i$ 的序列 $b_0, b_1, \ldots, b_{N-1}$，并将其对 $998244353$ 取模后输出。

### 【输入】

```
$N$ $c$
$a_0$ $a_1$ ... $a_{N-1}$
```

### 【输出】

```
$b_0$ $b_1$ ... $b_{N - 1}$
```

### 【输入样例】

```
5 3
1 2 3 4 5
```

### 【输出样例】

```
547 668 309 64 5
```

### 【输入样例2】

```
2 10000000
10000000 10000000
```

### 【输出样例2】

```
881938225 10000000
```

### 【数据范围】

- $1 \leq N \leq 524288$
- $0 \leq c, a_i < 998244353$
