### 【题目描述】

给定一个 $N \times N$ 的矩阵 $A = \lbrace a_{ij} \rbrace$，其中各元素属于 $\mathbb{Z}/998244353\mathbb{Z}$，请输出 $A^{-1} = \lbrace b_{ij} \rbrace$。如果它不存在，则输出 `-1`。

### 【输入】

```
$N$
$a_{11}$ $a_{12}$ ... $a_{1N}$
$a_{21}$ $a_{22}$ ... $a_{2N}$
:
$a_{N1}$ $a_{N2}$ ... $a_{NN}$
```

### 【输出】

如果不存在满足条件的矩阵，请输出

```
-1
```

否则，如果这样的矩阵存在，请输出

```
$b_{11}$ $b_{12}$ ... $b_{1N}$
$b_{21}$ $b_{22}$ ... $b_{2N}$
:
$b_{N1}$ $b_{N2}$ ... $b_{NN}$
```

### 【输入样例】

```
3
3 1 4
1 5 9
2 6 5
```

### 【输出样例】

```
188557267 255106890 587855008
122007643 987152749 321656514
576763404 310564910 976061145
```

### 【输入样例2】

```
3
1 2 3
4 5 6
7 8 9
```

### 【输出样例2】

```
-1
```

### 【输入样例3】

```
2
0 1
1 0
```

### 【输出样例3】

```
0 1
1 0
```

### 【数据范围】

- $1 \leq N \leq 500$
- $0 \leq a_{ij} < 998244353$
