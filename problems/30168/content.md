### 【题目描述】

给定 $Q$ 组询问。每组询问给定一个正整数 $N$，请判断它是否为质数。

### 【输入】

```
$Q$
$N_0$
$N_1$
$\vdots$
$N_{Q-1}$
```

### 【输出】

输出 $Q$ 行。若 $N$ 为质数，每行输出 `Yes`，否则输出 `No`。

### 【输入样例】

```
6
1
2
3
4
998244353
1000000000000000000
```

### 【输出样例】

```
No
Yes
Yes
No
Yes
No
```

### 【数据范围】

- $1 \leq Q \leq 100000$
- $1 \leq N \leq 1000000000000000000$
