### 【题目描述】

给定一个 $N \times M$ 的矩阵 $A$ 和一个 $N$ 维向量 $b$。请计算一个（$M$ 维）向量 $x$，使得 $Ax=b$。我们考虑的所有运算均在 $\mathbb{F}_{998244353}$ 中进行。

### 【输入】

```
$N$ $M$
$A_{0,0}$ $A_{0,1}$ ... $A_{0,M-1}$
$A_{1,0}$ $A_{1,1}$ ... $A_{1,M-1}$
:
$A_{N-1,0}$ $A_{N-1,1}$ ... $A_{N-1,M-1}$
$b_0$ $b_1$ ... $b_{N-1}$
```

### 【输出】

如果不存在解，输出

```
-1
```

否则输出如下内容。

```
$R$
$c_0$ $c_1$ ... $c_{M-1}$
$d_{0,0}$ $d_{0,1}$ ... $d_{0,M-1}$
:
$d_{R-1,0}$ $d_{R-1,1}$ ... $d_{R-1,M-1}$
```

其中，$R$ 是解空间的秩。$c_i$ 是一个解。对于每个 $j$，$d_{j,0}, ..., d_{j,M-1}$ 是解空间的一组基。

### 【输入样例】

```
2 3
1 2 3
4 5 6
50 122
```

### 【输出样例】

```
1
998244351 26 0
1 998244351 1
```

### 【数据范围】

- $1 \leq N, M \leq 500$
- $0 \leq A_{ij} < 998244353$
