### 【题目描述】

给定一棵 $N$ 个顶点的有根树，根为顶点 $0$。顶点 $i$ 的值为 $a_i$，其父亲为 $p_i$。依次处理以下 $Q$ 个查询：

- `0 $u$ $x$`：$a_u \gets a_u + x$
- `1 $u$`：输出以 $u$ 为根的子树中所有顶点的值之和。

### 【输入】

```
$N$ $Q$
$a_0$ $a_1$ ... $a_{N - 1}$
$p_1$ $p_2$ ... $p_{N - 1}$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
```

### 【输出】

对每个 `1 $u$` 查询，输出一行一个整数，表示以 $u$ 为根的子树中所有顶点的值之和。

### 【输入样例】

```
5 5
1 10 100 1000 10000
0 1 2 2
1 1
1 2
0 1 100000
1 0
1 3
```

### 【输出样例】

```
11110
11100
111111
1000
```

### 【数据范围】

- $1 \leq N, Q \leq 500,000$
- $0 \leq p_i < i$
- $0 \leq a_i, x \leq 10^9$
