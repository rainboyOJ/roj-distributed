# 第 1 题 Dijamant (`dijamant`)

> 时间限制 1.0 s · 空间限制 256 MB · 26 个测试点 · 全文比较（过滤行末空格及文末回车）

**本题使用文件输入输出**：输入文件 `dijamant.in`，输出文件 `dijamant.out`。

## 题目描述

桌上摆放有若干颗『钻石』。

当一个正方形旋转 $45^\circ$ 时，它就形成了『菱形』的形状。规定外形形如『菱形』且外边框均为 # 但内部均为 . 的图形为一颗『钻石』。

给定一个 $n \times m$ 大小的桌面，统计桌上摆放有多少颗『钻石』。

## 输入格式

第一行两个正整数 $n, m$，表示桌面的大小。

接下来的 $n$ 行，每行 $m$ 个字符 # 或 .，表示桌面。

## 输出格式

『钻石』的数量。

## 样例

### 样例 1

输入：

```text
7 25
.#...#....#....#....#....
#.#.#.#.#.#..#.#....#.#.#
.#....#....#....#....#...
....#..#.#..#..#..#.....#
.....#...#...#...#......#
....#.......#....#.#.#...
....#........#.....#..#..
```

输出：

```text
3
```

### 样例 2

输入：

```text
11 17
.....#.........#.
....#.#.........#
...#...#......#..
..#.....#....#.#.
.#.......#..#....
#.....#.#..#.....
.#.....#..#......
..#......#.......
...#......#......
....#.#..........
.....#...........
```

输出：

```text
1
```

### 样例 3

输入：

```text
5 11
##.#.###.##
#.#.#.#.#.#
.#.#.#.#.#.
#.#.#.#.#.#
##.#.###.##
```

输出：

```text
14
```

## 提示

### 样例 2 解释

看起来好像有 3 颗，但实际上有两个『菱形』互相包含，因此不符合『外边框均为 # 但内部均为 .』的定义。故只有 1 颗『钻石』。

### 数据规模与约定

**本题采用捆绑测试。**

- Subtask 1（20 pts）：$1 \le n, m \le 100$。
- Subtask 2（50 pts）：无特殊限制。

对于 100% 的数据，$1 \le n, m \le 2000$。
