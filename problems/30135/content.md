### 【题目描述】

给定一个 $N \times N$ 的矩阵 $A = \lbrace a_{ij} \rbrace$，其元素属于 $\mathbb{Z}/998244353\mathbb{Z}$。输出 $\operatorname{adj} A = \lbrace (-1)^{i+j}M_{ji} \rbrace$，其中 $M_{ij}$ 是从 $A$ 中删去第 $i$ 行和第 $j$ 列后所得矩阵的行列式。

### 【输入】

```
$N$
$a_{11}$ $a_{12}$ ... $a_{1N}$
$a_{21}$ $a_{22}$ ... $a_{2N}$
:
$a_{N1}$ $a_{N2}$ ... $a_{NN}$
```

### 【输出】

输出 $b_{ij} = (-1)^{i+j} M_{ji}$：

```
$b_{11}$ $b_{12}$ ... $b_{1N}$
$b_{21}$ $b_{22}$ ... $b_{2N}$
:
$b_{N1}$ $b_{N2}$ ... $b_{NN}$
```

### 【输入样例】

```
3
3 1 4
1 5 9
2 6 5
```

### 【输出样例】

```
998244324 19 998244342
13 7 998244330
998244349 998244337 14
```

### 【输入样例2】

```
3
1 2 3
4 5 6
7 8 9
```

### 【输出样例2】

```
998244350 6 998244350
6 998244341 6
998244350 6 998244350
```

### 【输入样例3】

```
2
0 1
1 0
```

### 【输出样例3】

```
0 998244352
998244352 0
```

### 【输入样例4】

```
1
0
```

### 【输出样例4】

```
1
```

### 【数据范围】

- $1 \leq N \leq 500$
- $0 \leq a_{ij} < 998244353$
