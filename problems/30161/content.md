### 【题目描述】

考虑正整数构成的集合：

$$S=\left\lbrace \left\lfloor \frac{N}{x} \right\rfloor \middle\vert x \in \mathbb{Z} , 1 \leq x \leq N \right\rbrace .$$

输出将 $S$ 中的元素按升序排序后得到的序列 $(a _ 0, a _ 1 , \ldots , a _ {k-1})$。

### 【输入】

```
$N$
```

### 【输出】

```
$k$
$a _ 0$ $a _ 1$ $\ldots$ $a _ {k-1}$
```

### 【输入样例】

```
10
```

### 【输出样例】

```
5
1 2 3 5 10
```

### 【数据范围】

- $1 \le N \le 1000000000000$
