# 联谊舞会

#### 题目描述
一年一度的联谊舞会开始了，每位学生都能交到自己心仪的朋友。

为了吸引同学参加，联谊舞会的主办方在今年想出了交友的新办法：主办方在舞厅中间画出了一条分界线，分界线的上方和下方都有一些从左往右的“站点”，每位同学都需要从一个分界线上方的“站点”跑到一个分界线下方的“站点”，如果两个同学的跑步路线相交，那么他们便交友成功。

需要注意的是，每位同学都和一个出发站点和一个结束站点唯一对应。

zzy 是社交领域专家，他很好奇这场舞会可以产生的最大“朋友圈”是多大，我们定义若干同学组成“朋友圈”当且仅当这些同学中任意两人均交友成功。

#### 输入格式

第一行一个正整数 $n$，代表同学个数。

接下来一行 $n$ 个数，第 $i$ 个数 为 $A_{i}$，代表第 $i$ 个出发站点所对应的同学。

接下来一行 $n$ 个数，第 $i$ 个数 为 $B_{i}$，代表第 $i$ 个结束站点所对应的同学。

#### 输出格式

输出一个整数，代表最大朋友圈的大小

#### 样例 #1

#### 样例输入 #1

```
4
3 4 1 2
4 3 2 1

```

#### 样例输出 #1

```
2
```

#### 样例输入 #2

```
3
1 2 3
3 2 1
```

#### 样例输出 #2

```
3
```

#### 数据范围与约定

对于所有数据，有：

-  $1 < n \le 10^5$

| 测试点编号  | 数据限制   | 特殊性质 |
| :---------: | :---------: |:---------: |
| $1 \sim 2$  |  $n \le 3$ |
| $3$  |  $n \le 10$ |
| $4 \sim 6$  | $n \le 1000$  | A |
| $7 \sim 9$ | $n \le 1000$ | |
| $10$ | $n \le 10^5$ | |

特殊性质 A：保证 $A_i=i$
