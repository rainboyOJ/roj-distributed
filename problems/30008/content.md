### 【题目描述】

本题包含 $T$ 组数据。
给定一个十六进制非负整数 $A$ 和一个十六进制正整数 $B$，输出满足以下等式的十六进制整数 $q, r$：

- $q = \left \lfloor \frac{A}{B} \right \rfloor$
- $A = qB + r$

### 【输入】

输入格式如下：

```
$T$
$A$ $B$
 $\vdots$
$A$ $B$
```

### 【输出】

输出格式如下：

```
$q$ $r$
 $\vdots$
$q$ $r$
```

### 【输入样例】

```
8
47 1F
50 1F
3 1F
0 1F
100000000000000000000 FFFFFFFFFF
1000000000000000000000000000000000 FFFF
10000000000000000000000000000000000000000 FFFFFFFFFFFFFFFFFFFF
FFFFFFFFFF FFFFFFFFFE
```

### 【输出样例】

```
2 9
2 12
0 3
0 0
10000000001 1
100010001000100010001000100010 10
100000000000000000001 1
1 1
```

### 【数据范围】

- $1 \leq T \leq 1600000$
- $0 \leq A < 16^{1600000}$
- $1 \leq B < 16^{1600000}$
- 对所有测试数据，$A$ 的字符数与 $B$ 的字符数之和不超过 $3200002$。
