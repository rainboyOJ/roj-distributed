# 矩形计数

题目描述
给定𝑛𝑛, 𝑚𝑚和平面上的𝑘𝑘个点(𝑋𝑋𝑖𝑖 , 𝑌𝑌𝑖𝑖 )，统计有多少个矩形其中左下角是(𝑥𝑥1 , 𝑦𝑦1 ), 右上角
是(𝑥𝑥2 , 𝑦𝑦2 )，满足1 ≤ 𝑥𝑥1 ≤ 𝑥𝑥2 ≤ 𝑛𝑛, 1 ≤ 𝑦𝑦1 ≤ 𝑦𝑦2 ≤ 𝑚𝑚，并且这个矩形(包括边界)里面
至少包含了前面𝑘𝑘个点中的一个。

输入格式
第一行，三个整数𝑛𝑛, 𝑚𝑚, 𝑘𝑘。

接下来𝑘𝑘行，每行两个整数𝑋𝑋𝑖𝑖 , 𝑌𝑌𝑖𝑖 。

输出格式
一个整数，表示答案。由于答案可能很大，输出对109 + 7取模的结果。

样例输入 1
10 10 2
8 8
1 7

样例输出 1
793

样例输入输出 2
见下发文件。

数据规模
共 10 组数据。

测试点1,2满足𝑛𝑛, 𝑚𝑚 ≤ 100。

测试点3,4满足𝑘𝑘 ≤ 2。

测试点5,6,7满足𝑘𝑘 ≤ 50。

对于所有数据，满足1 ≤ 𝑛𝑛, 𝑚𝑚 ≤ 109 , 0 ≤ 𝑘𝑘 ≤ 1000,1 ≤ 𝑋𝑋𝑖𝑖 ≤ 𝑛𝑛, 1 ≤ 𝑌𝑌𝑖𝑖 ≤ 𝑚𝑚。
