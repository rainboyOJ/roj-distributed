### 【题目描述】

给定整数 $r$、$d$ 和 $n$，求

$$\sum_{i=0}^{n-1} r^i i^d$$

对 $998244353$ 取模的结果。

规定 $0^0 = 1$。

### 【输入】

输入一行，包含 $r$、$d$ 和 $n$。

### 【输出】

输出一个整数 $\mathit{answer}$，表示答案。

### 【输入样例】

```
2 5 8
```

### 【输出样例】

```
2767418
```

### 【数据范围】

- $0 \le r < 998244353$
- $0 \le d \le 10000000$
- $0 \le n \le 1000000000000000000$
