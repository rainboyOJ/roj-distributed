### 【题目描述】

给定素数 $P$ 以及整数序列 $a_0, a_1, ..., a_{P - 1}$ 和 $b_0, b_1, ..., b_{P - 1}$。按如下方式计算整数序列 $c_0, c_1, ..., c_{P - 1}$：

$$c_k = \sum_{i \times j \equiv k \pmod{P}} a_i b_j \bmod 998244353$$

### 【输入】

```
$P$
$a_0$ $a_1$ ... $a_{P - 1}$
$b_0$ $b_1$ ... $b_{P - 1}$
```

### 【输出】

```
$c_0$ $c_1$ ... $c_{P - 1}$
```

### 【输入样例】

```
5
9 7 5 3 1
8 6 4 2 0
```

### 【输出样例】

```
308 64 60 36 32
```

### 【输入样例2】

```
2
0 998244352
0 998244352
```

### 【输出样例2】

```
0 1
```

### 【数据范围】

- $2 \leq P \leq 524288$
- $P$ 是素数
- $0 \leq a_i, b_i < 998244353$
