### 【题目描述】

给定一张由 $N$ 个顶点和 $M$ 条边构成的简单无向图 $G$。$G$ 的第 $i$ 条边为 $\lbrace u_i, v_i \rbrace$。$G$ 的每个顶点都带有一个整数值，其中第 $i$ 个顶点的值为 $x_i$。

求 $\displaystyle \prod_{i \in C} x_i$ 在 $G$ 的所有非空团 $C$ 上的和，并将该和模 $998244353$ 输出。

### 【输入】

```
$N$ $M$
$x_0$ $x_1$ $\ldots$ $x_{N-1}$
$u_0$ $v_0$
$u_1$ $v_1$
$\vdots$
$u_{M-1}$ $v_{M-1}$
```

### 【输出】

```
$A$
```

### 【输入样例】

```
3 2
1 2 3
0 1
1 2
```

### 【输出样例】

```
14
```

$(0), (1), (2), (0, 1), (1, 2)$ 都是 $G$ 的团。输出 $14$，即 $1 + 2 + 3 + 1 \cdot 2 + 2 \cdot 3 \bmod 998244353$ 的结果。

### 【输入样例2】

```
5 9
97644645 128903910 346967627 176460807 156955500
0 1
0 2
0 3
0 4
1 2
1 3
1 4
2 3
2 4
```

### 【输出样例2】

```
664902553
```

### 【数据范围】

- $1 \le N \le 100$
- $1 \le M \le 100$
- $0 \le x_i \lt 998244353$
- $0 \le u_i \lt N$
- $0 \le v_i \lt N$
- $u_i \neq v_i$
- $\lbrace u_i, v_i \rbrace \neq \lbrace u_j, v_j \rbrace \  (i \neq j)$
