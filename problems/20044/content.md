# 清澈

(transparent.cpp 1s/512MB)

## 题目描述

作为单身人士，钢琴曲是小 X 在碌碌生活中唯一的寄托，她很享受钢琴那清澈悦耳的音色。最近她对和弦进行非常感兴趣，一个和弦进行可以由一串范围在 $[1,k]$ 的有序数字描述，每个数字代表一个单独的和弦，相邻的数字一定不同，如 4536251 是经典的和弦进行之一，常见于流行乐。另一方面，小 X 是笨蛋，她只能通过音高的上下变化来区分和弦进行，而无法辨别出每个和弦的绝对音高。比如 4536251 和 1212121 在她的耳中是同一个和弦进行（音高变化的走向均为为上下上下上下），6456 和 6137 也会被当作同一和弦进行，但 16251 和 16751 就不会被当作同一和弦进行。

现在，小 X 手中有 $T$ 个和弦进行，第 $i$ 个和弦进行长度为 $l_i$。同时她又有一个长度为 $n$ 的和弦序列 $a$。她想要知道，对于第 $i$ 个和弦进行，她能否从 $a$ 中选一个子序列组成和弦进行使得它听起来和第 $i$ 个和弦进行相同。但是她实在是太笨了，只好来求助你，你能解答她的疑问吗？

## 输入格式

第一行包含一个整数 $n$，表示和弦序列 $a$ 的长度。

接下来一行包含 $n$ 个整数 $a_1, a_2, ..., a_n$。

接下来一行包含一个整数 $T$，表示小 X 有 $T$ 个和弦进行。

接下来 $T$ 行，每行包含一个整数 $l_i$，表示第 $i$ 个和弦进行的长度，以及 $l_i$ 个正整数，表示该和弦进行，保证和弦进行中不存在两个相邻的音高相同。

## 输出格式

对于每个和弦进行，第 $i$ 行输出一个字符串：
- 如果第 $i$ 个和弦进行可以从 $a$ 中选一个子序列组成，输出 `YES`。
- 否则，输出 `NO`。

## 输入输出样例 #1

### 输入 #1

```
6  
1 2 3 4 5 6  
3  
5 4 5 6 7 8  
6 3 5 7 8 10 12  
3 2 1 3
```

### 输出 #1

```
YES  
YES
NO
```

## 数据范围

对于 $10\%$ 的数据，$T=1,n\le 20$。

对于 $30\%$ 的数据，$\sum l_i,n\le 100$。

对于 $60\%$ 的数据，$\sum l_i,n\le 1000$。

另有 $10\%$ 的数据，$k=2$。

对于 $100\%$ 的数据，$T\le 100,\sum l_i,k\le 10^5,n\le 10^4$。
