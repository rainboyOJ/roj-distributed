### 【题目描述】

本题有 $T$ 组测试数据。

给定一张 **无向图** $G$，由 $N$ 个顶点和 $M$ 条边组成。第 $i$ 条边连接顶点 $u_i$ 和 $v_i$。这张图不一定是简单图。

$G$ 的 **欧拉路径**（eulerian trail）是一对序列：顶点序列 $(v_0,\ldots,v_M)$ 与边序列 $(e_0,\ldots,e_{M-1})$，满足以下条件。

- $(e_0,\ldots,e_{M-1})$ 是 $(0, \ldots, M-1)$ 的一个排列。
- 对于 $0\leq i < M-1$，边 $e_i$ 连接 $v_i$ 和 $v_{i+1}$。

判断 $G$ 是否存在欧拉路径，若存在则输出一条。

### 【输入】

```
$T$
$N$ $M$
$u_0$ $v_0$
$\vdots$
$u_{M-1}$ $v_{M-1}$
$N$ $M$
$u_0$ $v_0$
$\vdots$
$u_{M-1}$ $v_{M-1}$
$\vdots$
```

### 【输出】

如果不存在欧拉路径，输出 `No`。否则按以下格式输出一条欧拉路径。

```
Yes
$v_0$ $\ldots$ $v_{M}$
$e_0$ $\ldots$ $e_{M-1}$
```

### 【数据范围】

- $1 \leq T \leq 100000$
- $1 \leq N \leq 200000$
- $0 \leq M \leq 200000$
- $0 \leq u_i, v_i \lt N$
- 所有测试数据的 $N$ 之和不超过 $200000$。
- 所有测试数据的 $M$ 之和不超过 $200000$。
