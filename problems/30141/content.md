### 【题目描述】

给定一个 $N \times N$ 的矩阵 $M = \lbrace a_{ij} \rbrace$。输出 $\mathrm{det}(M) \bmod 998244353$。

### 【输入】

输入格式如下：

```
$N$
$a_{11}$ $a_{12}$ ... $a_{1N}$
$a_{21}$ $a_{22}$ ... $a_{2N}$
:
$a_{N1}$ $a_{N2}$ ... $a_{NN}$
```

### 【输出】

输出 $\mathrm{det}(M) \bmod 998244353$。

### 【输入样例】

```
3
3 1 4
1 5 9
2 6 5
```

### 【输出样例】

```
998244263
```

### 【输入样例2】

```
3
1 2 3
4 5 6
7 8 9
```

### 【输出样例2】

```
0
```

### 【输入样例3】

```
2
0 1
1 0
```

### 【输出样例3】

```
998244352
```

### 【数据范围】

- $1 \leq N \leq 500$
- $0 \leq a_{ij} < 998244353$
