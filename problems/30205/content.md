### 【题目描述】

给定一个次数为 $N$ 的多项式 $f(x) = \sum_{i=0}^N f_i x^i \in \mathbb{F}_{998244353}[x]$。
求出所有满足 $f(a)=0$ 的 $a \in \mathbb{F}_{998244353}$。

### 【输入】

```
$N$
$f_0$ $\cdots$ $f_N$
```

### 【输出】

按照以下格式输出所有满足 $f(a)=0$ 的 $a$。

```
$n$
$a_0$ $\cdots$ $a_{n-1}$
```

$a_i$ 应输出为小于 $998244353$ 的非负整数。
$a_i$ 的输出顺序可以是任意的。

### 【输入样例】

```
2
6 998244348 1
```

### 【输出样例】

```
2
3 2
```

### 【输入样例2】

```
2
3 0 1
```

### 【输出样例2】

```
0

```

### 【输入样例3】

```
5
1 5 10 10 5 1
```

### 【输出样例3】

```
1
998244352
```

### 【输入样例4】

```
10
0 961956353 102657600 880974353 72368000 971311853 6327300 997299353 87000 998239853 100
```

### 【输出样例4】

```
10
1 3 0 2 4 5 9 8 7 6
```

### 【数据范围】

- $0\leq N\leq 4000$
- $0\leq f_i < 998244353$
- $f_N\neq 0$
