### 【题目描述】

本题有 $T$ 组数据。
给定整数 $A$ 和 $B$，输出 $A+B$。

### 【输入】

第一行一个整数 $T$。

接下来 $T$ 行，每行两个整数 $A$ 和 $B$。

```
$T$
$A$ $B$
 $\vdots$
$A$ $B$
```

### 【输出】

输出 $T$ 行，每行一个整数。

```
$A+B$
 $\vdots$
$A+B$
```

### 【输入样例】

```
9
47 10
50 10
3 -10
0 -10
-12 -34
12345678901234567890 98765432109876543210
-12345678901234567890 98765432109876543210
-12345678901234567890 -98765432109876543210
12345678901234567890 -12345678901234567890
```

### 【输出样例】

```
57
60
-7
-10
-46
111111111011111111100
86419753208641975320
-111111111011111111100
0
```

### 【数据范围】

- $1 \leq T \leq 200000$
- $0 \leq |A|, |B| < 10^{2000000}$
- 所有数据中（$A$ 的字符个数）$+$（$B$ 的字符个数）之和不超过 $4000002$。
