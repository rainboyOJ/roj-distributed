# 追忆

(recall.cpp 1s/512MB)

## 题目描述

“忆昔午桥桥上饮，坐中皆是豪英……”课堂上的小 X 听到这熟悉的词句，突然想起了在机房与众人玩耍的快乐时光。陷入追忆的她恍然看见她在和小 L 互相随机说话，说出来的话可以用 $n$ 个只包含小写字符的字符串 $s_1,s_2,\cdots,s_n$。已知小 X 说出来的字符串一定能被重排为回文串（正着读和反着读一样，如`abba`），小 L 说出来的话一定能被重排为循环串（可以由某个字符串重复至少两次得到，如 `bababa`）。现在，小 X 想请你判断一下，这 $n$ 个字符串里有哪些一定是小 X 说的，有哪些一定是小 L 说的，还有哪些既可能是小 X 说的也可能是小 L 说的。

## 输入格式

第一行一个正整数 $n$。

接下来 $n$ 行，第 $i$ 行包含一个字符串 $s_i$。

## 输出格式

共 $n$ 行。对于第 $i$ 行，如果 $s_i$ 一定是小 X 说的，输出 `X`；如果一定是小 L 说的，输出 `L`；否则输出 `XL`。

## 输入输出样例 #1

### 样例输入 #1

```
6
a
aa
aab
aaabbb
aabbccd
aaabbbcccddd
```

### 样例输出 #1

```
X
XL
X
L
X
L
```

## 数据范围

记 $|s|$ 表示字符串 $s$ 的长度。

对于 $50\%$ 的数据，$|s_i|\le 5$。

对于 $100\%$ 的数据，$\sum |s_i|\le 10^5,n\le 1000$。
