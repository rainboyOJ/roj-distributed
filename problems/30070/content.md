### 【题目描述】

把一个 $n$ 元集合划分成若干个非空子集的方案数称为 Bell 数 $B_n$。
给定 $N$，输出 $B_0, \ldots, B_N$ 分别除以 $998244353$ 的余数。

### 【输入】

```
$N$
```

### 【输出】

```
$B_0$ $B_1$ ... $B_N$
```

### 【输入样例】

```
10
```

### 【输出样例】

```
1 1 2 5 15 52 203 877 4140 21147 115975
```

### 【数据范围】

- $0 \leq N \leq 500000$
