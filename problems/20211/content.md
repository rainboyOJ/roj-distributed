# 春江潮水连海平

### 题目信息

时间限制:  `1s`

空间限制: `512M`

输入文件: `water.in`

输出文件: `water.out`

### 题目描述

> 春江潮水连海平，海上明月共潮生。  
> 滟滟随波千万里，何处春江无月明。

有一条小河，最上游的坐标为 $H$，最下游坐标为 $1$。河水从上游流到下游，你可以忽略水流的速度。不会有新的河水注入这条河。

初始整条河每个坐标都有 $1$ 单位河水。而 $h_i$ 坐标会在 $t_i$ 时刻起打开一个排水口，每个排水口每 $1$ 单位时间可以排出 $1$ 单位的河水。注意每个排水口在 $t_i+1$ 时刻才开始排水，并且只会排出 $h_i$ 上游的水。

请问多久可以排出所有河水，答案四舍五入保留六位小数，或报告不可能，输出 $-1$。

### 输入格式

第一行两个整数 $H,q$，代表上游坐标与出现的排水口总数。

接下来 $q$ 行，每行两个整数 $t_i,h_i$。

### 输出格式

一行一个数表示答案。

### 样例

#### 样例输入 #1

```
7 3
2 0
2 0
2 0
```

#### 样例输出 #1

```
4.333333
```

#### 样例解释 #1

$2$ 时刻在 $0$ 位置出现了三个排水口，一共排出 $1$ ~ $7$ 共 $7$ 单位的水。花费时间 $2+7/3=4.333333$

#### 样例输入 #2

```
10 3
5 0
8 6
9 1
```

#### 样例输出 #2

```
12.250000
```
#### 样例输入 #3

```
11 2
3 1
4 11
```

#### 样例输出 #3

```
-1
```

### 数据范围与提示

对于所有数据，有：

-  $h_i < H \le 10^9, t_i \le 10^9$ , $q \le 10^5$

| 测试点编号  |      特殊性质       |
| :---------: | :-----------------: |
| $1 \sim 2$  |      $t_i = 0$      |
| $3 \sim 4$  |      $h_i = 0$      |
| $5 \sim 6$  | $q,H，t_i \le 1000$ |
| $7 \sim 10$ |         无          |
