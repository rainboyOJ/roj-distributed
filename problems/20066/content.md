# 十五十五

## 题目描述

两个外星人在玩名叫十五十五的游戏。两个外星人分别有 $n$ 只手，每只手有 $k$ 只手指。在一轮游戏中，外星人的每只手都可以握拳或完全张开——握拳则有 $0$ 只手指，完全张开则有 $k$ 只手指。同时，两个外星人要各报一个数，如果最终两个人出出来的手指总数等于某个人报的数，那么这个人就赢了。

你是一名旁观者，通过某种方法，你已经知道了外星人 $A$ 的每只手将要出握拳还是完全张开，但不知道外星人 $B$ 每只手要出什么。在场有 $q$ 位观众，第 $i$ 位观众猜测了一个数字 $x_i$，他想让你告诉他，外星人 $B$ 是否有一种符合上述游戏规则的出拳方式，使得最终总手指数恰好为 $x_i$。

## 输入格式

第一行三个以空格分隔的正整数 $n,k,q$，表示每个外星人的手的数量，和每只手的手指数量。

第二行一个由 `0` 和 `1` 构成的长度为 $n$ 的字符串，第 $i$ 个字符描述外星人 $A$ 的第 $i$ 只手将出什么，`1` 表示完全张开，`0` 表示握拳。

第三行 $q$ 个以空格分隔的非负整数 $x_1\dots x_q$，表示观众们猜的数字。

## 输出格式

共 $q$ 行，第 $i$ 行包含一个字符串 `Yes` 或 `No`，其中 `Yes` 表示存在一种方式使总和为 $x_i$，`No` 表示不存在这种方式。

## 样例输入

```
3 5 4
101
15 4 25 23
```

## 样例输出

```
Yes
No
Yes
No
```

以 $15$ 为例，外星人 $B$ 出 `100` 即可。

## 数据范围

本题共包含 $10$ 个测试点。对于全部测试数据，$1\le n,q\le 10^5,1\le k\le 10^9,\forall 1\le i\le q,0\le x_i\le 10^{18}$。

| 测试点编号 | $n,q\le$ | 特殊性质  |
| :--------: | :------: | :-------: |
|    $1$     |   $1$    |     -     |
| $2\sim 3$  |  $100$   | $k\le 10$ |
| $4\sim 6$  |  $10^5$  |   $k=1$   |
| $7\sim 10$ |  $10^5$  |           |
