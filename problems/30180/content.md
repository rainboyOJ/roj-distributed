### 【题目描述】

给定一个整数序列 $a_0, \ldots, a_{N-1}$。

请找出长度 $d \ge 0$ 最小的整数序列 $c_1, \ldots, c_d$，满足对于 $1 \le j \le d$ 有 $0 \le c_j < 998244353$，并且
$$a_i \equiv \sum_{j=1}^d c_j a_{i-j} \pmod{998244353} \quad \text{对于} \quad d \le i < N.$$ 

### 【输入】

输入格式如下：

```
$N$
$a_0$ $\ldots$ $a_{N-1}$
```

### 【输出】

输出格式如下：

```
$d$
$c_1$ $\ldots$ $c_d$
```

如果有多个能使 $d$ 最小的答案，输出其中任意一个。

### 【输入样例】

```
6
3 4 6 10 18 34
```

### 【输出样例】

```
2
3 998244351
```

### 【输入样例2】

```
6
3 4 6 10 18 36
```

### 【输出样例2】

```
4
3 998244351 3 998244349
```

### 【输入样例3】

```
0
```

### 【输出样例3】

```
0
```

### 【输入样例4】

```
5
0 0 0 0 1
```

### 【输出样例4】

```
5
0 0 0 0 0
```

### 【数据范围】

- $0 \le N \le 10000$
- $0 \le a_i < 998244353$
