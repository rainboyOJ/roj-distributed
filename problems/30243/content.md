### 【题目描述】

给定一棵有 $N$ 个顶点的有根树。树的根是顶点 $0$。顶点 $i$ 的父亲是 $p_i$。通过为每个顶点选作根，你将得到 $N$ 棵有根子树。请按有根树同构关系将它们分类。

输出互不相同的子树个数 $K$ 以及一个整数序列 $a_0, a_1, \ldots, a_{N-1}$，满足以下条件：

- $0 \leq a_i < K$
- $a_i = a_j$ 当且仅当以 $i$ 和 $j$ 为根的两棵子树同构。

### 【输入】

~~~
$N$
$p_1$ $p_2$ $\ldots$ $p_{N-1}$
~~~

### 【输出】

~~~
$K$
$a_0$ $a_1$ $\ldots$ $a_{N-1}$
~~~

若有多组解，输出任意一组即可。

### 【输入样例】

```
11
0 1 1 2 2 0 6 6 8 8
```

### 【输出样例】

```
4
3 2 1 0 0 0 2 0 1 0 0
```

### 【输入样例2】

```
5
0 1 2 3
```

### 【输出样例2】

```
5
4 3 2 1 0
```

### 【数据范围】

- $1 \leq N \leq 500000$
- $0 \leq p_i < i$
