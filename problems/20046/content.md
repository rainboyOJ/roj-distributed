# 十字斩

#### 题目描述
zzy 是某大学新生，在迎新晚会上，老师向大家介绍了十字斩活动。

活动场地可以视为一个具有坐标轴的无限平面直角坐标系。坐标系中有许多气球，气球的坐标可以用 $(x,y)$ 刻画 $(-10^8 \le x,y \le 10^8)$，而学生们的目标是用十字斩来破坏最多的气球。

十字斩可以形象的刻画为相互垂直的两条直线，并且每条直线与 $x$ 轴 $y$ 轴的夹角均为 $45^\circ$。使用十字斩后，两条直线上的气球均被破坏。

zzy 想要赢得这场活动的胜利，走向大学人生巅峰。于是他选了若干个位置，想问你如果他站在这些位置释放十字斩，他能破坏多少气球。

#### 输入格式

第一行两个正整数 $n$，$m$ 代表气球数量和询问数量。

接下来 $n$ 行，每行两个整数，代表气球坐标，保证坐标两两不同。

接下来 $m$ 行，每行两个整数，代表询问坐标。

#### 输出格式

$m$ 行，每行一个整数，代表可以破坏的气球数量

#### 样例输入 #1

```
4 2
0 0
2 2
0 2
2 0
0 1
1 1

```

#### 样例输出 #1

```
0
4
```

#### 数据范围与约定

对于所有数据，有：

-  $-10^8 \le x,y \le 10^8$
-  $0 < n,m \le 10^5$

| 测试点编号  |  数据限制   |
| :---------: | :---------: |
| $1\sim 3$ | $0 < x,y,m \le 100$ |
| $4 \sim 5$ | $0 < x,y,m \le 1000$ |
| $6 \sim 8$ | $0 < x,y,m \le 10^5$ |
| $9 \sim 10$ |  |
