# 小明与杂草大作战

### 题目描述

小明家的花园里长满了 $N$ 棵杂草，每棵杂草的高度分别是 $A_1, A_2, \ldots, A_N$。

小明和他的好朋友小华决定分工合作来清理这些讨厌的杂草：

* 小华最多可以先拔掉 $K$ 棵任意的杂草（当然，也可以一棵都不拔）。
* 接着小明将反复进行以下操作，直到花园里不剩任何杂草：

  * 设此时剩下最高的杂草高度为 $H$，小明一次性拔掉所有高度超过 $\frac{H}{2}$ 的杂草。

小华希望：

1. 尽量让小明的操作次数最少；
2. 如果有多种方案能做到相同的最少操作次数，小华还希望自己拔的杂草数量也尽量少。

请你帮忙计算：

* 小明最终需要的最少操作次数；
* 在这种情况下，小华需要拔多少棵杂草。

### 输入格式

第一行包含两个整数 $N, K$（$1 \le N \le 2 \times 10^5$, $0 \le K \le N$）。

第二行包含 $N$ 个整数 $A_1, A_2, \ldots, A_N$（$1 \le A_i \le 10^9$）。

### 输出格式

输出两个整数：小明的最少操作次数和小华需要拔掉的杂草数，中间用空格隔开。

### 样例

#### 样例 1 输入

```
4 1
2 3 4 9
```

#### 样例 1 输出

```
2 1
```

#### 样例 1 解释

* 小华拔掉最高的那棵杂草（高度 $9$）。
* 此时剩下最高的是高度 $4$，$\frac{4}{2}=2$，小明一次性拔掉比 $2$ 高的杂草，也就是拔掉高度为 $4$ 和 $3$ 的。
* 最后剩下高度为 $2$ 的杂草，再进行一次操作拔掉。
* 总共 $2$ 次操作，小华拔了 $1$ 棵杂草。

#### 样例 2 输入

```
3 3
2 3 5
```

#### 样例 2 输出

```
0 3
```

#### 样例 2 解释

* 小华直接拔掉全部 $3$ 棵杂草，小明就不用操作了。

#### 样例 3 输入

```
9 8
137 55 56 60 27 28 133 56 55
```

#### 样例 3 输出

```
1 4
```

### 数据范围与提示

* $1 \le N \le 2 \times 10^5$, $0 \le K \le N$
* $1 \le A_i \le 10^9$
  
| 测试点编号 | 数据范围         | 
|-------|---------------------|
| $1\sim2$   | $1 \leq N \leq 20，1 \leq A_i \leq 10^3$     |   
| $3\sim5$   | $1 \leq N \leq 2 \times 10^{3}，1 \leq A_i \leq 10^5$   |  
| $6\sim10$  |  $1 \le N \le 2 \times 10^5, 1 \le A_i \le 10^9$ |
