### 【题目描述】

给定 $N$ 个正整数 $s_0,s_1,\ldots,s_{N-1}$ 以及一个正整数 $T$。

对于每个 $t=1,2,...,T$，统计满足 $\sum_{i \in I} s_i=t$ 的子集 $I \subseteq \lbrace 0,1,...,N-1\rbrace$ 的个数，并输出其对 $998244353$ 取模的结果（记为 $p_t$）。

### 【输入】

```
$N$ $T$
$s_0$ $s_1$ ... $s_{N-1}$
```

### 【输出】

```
$p_1$ $p_2$ ... $p_T$
```

### 【输入样例】

```
5 3
1 1 2 2 3
```

### 【输出样例】

```
2 3 5
```

### 【数据范围】

- $1 \leq N \leq 1000000$
- $1 \leq T \leq 500000$
- $1 \leq s_i \leq T$
