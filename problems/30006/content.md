### 【题目描述】

本题共有 $T$ 组数据。
给定十六进制整数 $A$ 与 $B$，输出十六进制整数 $A+B$。

### 【输入】

```
$T$
$A$ $B$
 $\vdots$
$A$ $B$
```

### 【输出】

```
$A+B$
 $\vdots$
$A+B$
```

### 【输入样例】

```
9
47 FF
50 FF
3 -FF
0 -FF
-A0 -EFE

-1234567890ABCDEF1234567890ABCDEF FEDCBA9876543210FEDCBA9876543210
-1234567890ABCDEF1234567890ABCDEF -FEDCBA9876543210FEDCBA9876543210
1234567890ABCDEF1234567890ABCDEF -1234567890ABCDEF1234567890ABCDEF
```

```
146

```

### 【数据范围】

- $1 \leq T \leq 160000$
- $0 \leq |A|, |B| < 16^{1600000}$
- 所有测试数据中（$A$ 的字符数）$+$（$B$ 的字符数）之和不超过 $3200002$。
