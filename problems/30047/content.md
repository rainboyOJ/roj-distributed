### 【题目描述】

给定一个长度为 $N$ 的整数序列 $a_0, a_1, \dots, a_{N - 1}$。依次处理以下 $Q$ 个查询：

- `0 $l$ $r$ $x$`：对每个 $i = l, l+1, \dots, {r - 1}$，令 $a_i \gets a_i + x$。
- `1 $l$ $r$`：输出 $\min_{l \le i \le r-1} a_i$。

### 【输入】

输入以如下格式给出：

```
$N$ $Q$
$a_0$ $a_1$ ... $a_{N - 1}$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
```

### 【输出】

对每个 `1 $l$ $r$` 查询，输出一行一个整数，表示 $\min_{l \le i \le r-1} a_i$。

### 【输入样例】

```
5 7
1 2 3 4 5
1 0 5
0 0 3 3
1 1 4
0 1 4 -5
1 0 3
0 4 5 -100
1 0 5
```

### 【输出样例】

```
1
4
0
-95
```

### 【数据范围】

- $1 \leq N, Q \leq 500000$
- $|a_i|, |x| \leq 1000000000$
- $0 \leq l < r \leq N$
- 输入中的所有值均为整数。
