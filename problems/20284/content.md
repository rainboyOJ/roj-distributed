# 公共子序列

题目描述
有𝑘𝑘个序列𝑎𝑎1 , 𝑎𝑎2 , … , 𝑎𝑎𝑘𝑘 ，每个序列的长度都是𝑛𝑛，并且每个元素都是1到𝑛𝑛之间等概
率随机生成的整数。

问这𝑘𝑘个串有多少个长度大于0的公共子序列。在每个序列中都选出一些位置，并
将这些位置对应的数字依次拼起来，当它们都相等时，称其为公共子序列。

答案可能很大，输出对109 + 7取模的结果。

输入格式
第一行两个整数𝑘𝑘, 𝑛𝑛。

接下来𝑘𝑘行，每行𝑛𝑛个整数𝑎𝑎𝑖𝑖,𝑗𝑗 表示序列，序列随机生成。

输出格式
一个整数，表示答案。

样例输入 1
3 3
1 2 3
2 3 1
1 2 3

样例输出 1
4

样例输入输出 2
见下发文件。

数据规模
共 10 个测试点。

测试点1,2满足𝑘𝑘 = 2。

测试点3,4满足𝑘𝑘 = 3。

测试点5,6满足𝑛𝑛 ≤ 50。

对于所有数据，满足2 ≤ 𝑘𝑘 ≤ 5,1 ≤ 𝑛𝑛 ≤ 3000。
