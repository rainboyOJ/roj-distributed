### 题目描述

你正在协助一位机器人在一块能源矿区中执行采集任务。这片矩形区域由多个单元格组成，部分区域埋藏有不同等级的能量晶体，其余区域则布满了无法通行的废墟。

任务开始时，机器人从某一个晶体所在的位置出发。机器人只能上下左右四个方向移动，不能穿越废墟，也不能移动到空地之外。每到达一个单元格，若其中有晶体，机器人会自动采集。

不同等级的晶体具有不同的价值：

- 低阶晶体（S）：价值 1 能量单位
- 中阶晶体（M）：价值 5 能量单位
- 高阶晶体（L）：价值 10 能量单位
- 废墟（*）：无法通过，不可采集

你的任务是计算机器人能够采集到的晶体的总价值。

### 输入格式

- 第一行包含一个整数 $R > 0$，表示矿区的行数。
- 第二行包含一个整数 $C > 0$，表示矿区的列数。
- 接下来 $R$ 行，每行包含 $C$ 个字符，表示整个矿区地图：
  - S 表示低阶晶体；
  - M 表示中阶晶体；
  - L 表示高阶晶体；
  - \* 表示废墟。
- 接下来包含两行两个整数：
  - A：起始位置的行号（$0 \leq A < R$）
  - B：起始位置的列号（$0 \leq B < C$）

地图的左上角是第 0 行第 0 列。

### 输出格式

输出一个整数，表示机器人能采集到的晶体总价值。

### 数据范围

| **分值** | **描述**                                       | **范围**               |
| -------- | ---------------------------------------------- | ---------------------- |
| 10       | 矿区面积很小，且不存在任何废墟障碍。           | $R \times C \leq 100$  |
| 30       | 矿区面积很小，废墟将矿区划分为若干矩形采集区。 | $R \times C \leq 100$  |
| 30       | 矿区面积很小，且废墟可出现在任意位置。         | $R \times C \leq 100$  |
| 30       | 矿区面积可能较大，且废墟可任意分布于矿区中。   | $R \times C \leq 10^5$ |

对于所有数据，$1\leq R,C\leq 10^5$，$1\leq R\times C\leq 10^5$ 。
