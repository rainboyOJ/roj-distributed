### 【题目描述】

给定一个 $2N \times 2N$ 的交替矩阵 $M = \lbrace a_{ij} \rbrace$。输出 $\mathrm{Pf}(M) \bmod 998244353$。

### 【输入】

```
$N$
$a_{1,1}$ $a_{1,2}$ ... $a_{1,2N}$
$a_{2,1}$ $a_{2,2}$ ... $a_{2,2N}$
:
$a_{2N,1}$ $a_{2N,2}$ ... $a_{2N,2N}$
```

### 【输出】

输出 $\mathrm{Pf}(M) \bmod 998244353$。

### 【输入样例】

```
2
0 1 2 3
998244352 0 4 5
998244351 998244349 0 6
998244350 998244348 998244347 0
```

### 【输出样例】

```
8
```

### 【输入样例2】

```
1
0 1
998244352 0
```

### 【输出样例2】

```
1
```

### 【数据范围】

- $1 \leq N \leq 300$
- $0 \leq a_{ij} < 998244353$
