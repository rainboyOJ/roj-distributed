### 【题目描述】

本题共有 $T$ 组测试数据。

给定一个非负整数 $N$，输出 $N!$ 对 $998244353$ 取模后的结果。

### 【输入】

```
$T$
$N_1$
$\vdots$
$N_T$
```

### 【输出】

输出 $N!$ 对 $998244353$ 取模后的结果。

### 【输入样例】

```
5
0
5
100
1234567
998244352
```

### 【输出样例】

```
1
120
35305197
972177311
998244352
```

### 【数据范围】

- $1\leq T\leq 5$
- $0 \leq N < 998244353$
