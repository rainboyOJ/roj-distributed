# 第 1 题 反回文 (`antipalindrome`)

> 时间限制 1.0 s · 空间限制 256 MB · 49 个测试点 · 全文比较（过滤行末空格及文末回车）

**本题使用文件输入输出**：输入文件 `antipalindrome.in`，输出文件 `antipalindrome.out`。

## 题目描述

Bajtek 今天过生日。他收到了一份礼物——一袋磁性字母。他立刻跑到冰箱前，开始从左到右把字母贴上去。Bajtek 可以按任意顺序贴字母，但不能旋转它们。他想尽量多贴字母，最好全部贴上。

不一会儿，他陷入了恐慌：如果拼出的单词中包含回文（长度至少为 2 的连续片段，从左读和从右读相同）怎么办？Bajtek 非常讨厌回文，他非常希望冰箱上的字母能组成尽可能长的、不含任何回文片段的单词。例如，单词 abcadbc 是可以接受的，但 abacd 和 babba 不行，因为它们分别包含回文片段 aba 和 bb。

## 输入格式

输入第一行（也是唯一一行）是一个非空字符串，由英文小写字母组成，即 Bajtek 袋子里可用的磁性字母。字符串长度不超过 $1000000$。

## 输出格式

输出第一行（也是唯一一行）应给出由袋中字母构造的最长的不含回文的单词。

如果存在多个正确答案，你的程序可以输出任意一个。

## 样例

### 样例 1

输入：

```text
adabacab
```

输出：

```text
abcabda
```

### 样例 2

输入：

```text
abcde
```

输出：

```text
edcba
```

### 样例 3

输入：

```text
aaaaaaa
```

输出：

```text
a
```

## 数据范围与子任务

| 附加限制 | 分数 |
| --- | --- |
| 袋中只有字母 a 和 b | 12 |
| 袋中只有字母 a、b、c | 25 |
| 袋中不超过 10 个字母 | 20 |
| 袋中不超过 $100000$ 个字母 | 80 |

其余样例测试：

- `ant0d`：33 333 个字母 a，接着同样多的 b，最后同样多的 c；
- `ant0e`：长度为 999 986 的字符串，由英文字母表重复 38 461 次组成。
