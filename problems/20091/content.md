# 小明与巨大的数字

### 题目描述

小明最近迷上了研究“大”数。在小明眼中，一个正整数 $x$ 如果满足：

$$
x - \mathrm{sum}(x) \geq s
$$

就被称为巨大的数字。
其中 $\mathrm{sum}(x)$ 表示 $x$ 的各位数字之和。

现在，小明想知道：不超过 $n$ 的数字中，有多少个是巨大的？

### 输入格式

一行两个整数 $n, s$（$1 \le n, s \le 10^{18}$）。

### 输出格式

输出满足条件的数字个数。

### 样例

#### 样例 1 输入

```
12 1
```

#### 样例 1 输出

```
3
```

#### 样例 2 输入

```
25 20
```

#### 样例 2 输出

```
0
```

#### 样例 3 输入

```
17777889 1000000
```

#### 样例 3 输出

```
16777880
```

### 数据范围与提示

* $1 \le n, s \le 10^{18}$
  
| 测试点编号 | 数据范围         | 
|-------|---------------------|
| $1\sim2$   | $1 \leq n \leq 10^{8}，1 \leq s \leq 10^8$     |   
| $3\sim4$   | $1 \leq n \leq 10^{8}，1 \leq s \leq 10^{18}$   |  
| $5\sim10$  | $1 \leq n, s \leq 10^{18}$ |
