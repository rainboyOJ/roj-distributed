## 题目描述

给定一个仅由小写字母组成的字符串 $t$，它由某个字符串 $s$ 与其去除所有字符 `a` 后所得的字符串 $s'$ 拼接而成，即 $t = s + s'$。

请还原原始字符串 $s$，或判断无解。

## 输入格式

第一行一个整数 $T$，表示数据组数。

每组数据输入一行，一个字符串，表示 $t$。

## 输出格式

每组数据输出一行，一个字符串，若有解，输出 $s$，否则输出 `No solution!`。

## 样例 #1

```input1
2
aabaacbaba
acbaabcbaacbbcb
```

```output1
No solution!
acbaabcbaa
```
