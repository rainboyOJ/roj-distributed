### 【题目描述】

给定一个 $N$ 个顶点、$M$ 条边的无向图。第 $i$ 条边为 $(a_i, b_i)$。这张图不一定是简单图。

请把这张图分解为三边连通分量。

### 【输入】

```
$N$ $M$
$a_0$ $b_0$
$a_1$ $b_1$
:
$a_{M - 1}$ $b_{M - 1}$
```

### 【输出】

第一行输出三边连通分量的个数 $K$。

接下来 $K$ 行，按如下格式输出。其中 $l$ 是三边连通分量中顶点的个数，$v_i$ 是顶点编号。

```
$l$ $v_0$ $v_1$ ... $v_{l-1}$
```

若有多组合法解，输出任意一组均可。

### 【输入样例】

```
4 5
0 2
0 1
3 0
2 1
2 3
```

### 【输出样例】

```
3
2 0 2
1 1
1 3
```


### 【输出样例2】

```
6

1 6
2 7 8
```

### 【数据范围】

- $1 \leq N \leq 200000$
- $1 \leq M \leq 200000$
- $0 \leq a_i, b_i < N$
