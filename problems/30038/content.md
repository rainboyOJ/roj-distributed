### 【题目描述】

给定一个长度为 $N$ 的整数序列 $a_0, a_1, \dots, a_{N-1}$。
令 $A_{-1}$ 表示序列 $(a_0, a_1, \dots, a_{N-1})$。

对于 $i=0,1,\ldots,Q-1$，依次处理如下查询：

- `0 k l r b c`：将 $A_k$ 复制一份作为 $A_i$。对 $A_i$ 中的每个 $j = l, l+1, \dots, r - 1$，令 $a_j \gets b \times a_j + c$。
- `1 k s l r`：将 $A_k$ 复制一份作为 $A_i$。对 $A_i$ 中的每个 $j = l, l+1, \dots, r - 1$，令 $a_j \gets a'_j$（其中 $a'_j$ 是 $a_j$ 在 $A_s$ 中的值）。
- `2 k l r`：输出 $A_k$ 中的 $\sum_{j = l}^{r - 1} a_j \bmod 998244353$。

### 【输入】

```
$N$ $Q$
$a_0$ $a_1$ ... $a_{N-1}$
$\textrm{Query}_0$
$\vdots$
$\textrm{Query}_{Q-1}$
```

### 【输出】

对每个类型为 `2` 的查询输出一行一个整数。

### 【数据范围】

设 $t_i$ 表示第 $i$ 个查询的类型（$0\leq i \lt Q$，$t_i\in\lbrace 0,1,2\rbrace$）。

- $1 \leq N \leq 100000$
- $1 \leq Q \leq 100000$
- $0 \leq a \lt 998244353$
- $1 \leq b \lt 998244353$
- $0 \leq c \lt 998244353$
- $-1 \leq k \lt i$
- $k=-1$ 或 $t_k\in\lbrace 0,1\rbrace$
- $-1 \leq s \lt i$
- $s=-1$ 或 $t_s\in\lbrace 0,1\rbrace$
- $0 \leq l \lt r \leq N$
