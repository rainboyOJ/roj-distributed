### 【题目描述】

本题有 $T$ 组数据。

给定严格凸多边形按逆时针顺序排列的顶点 $p_i(x_i, y_i)$（$0 \leq i < N$）。

对每个 $i$，求出一个下标 $f_i$（$0 \leq f_i < N$），使得

$$
\operatorname{dist}(p_i, p_{f_i}) = \max_{0 \leq j < N}\operatorname{dist}(p_i, p_j).
$$

其中，$\operatorname{dist}$ 表示欧几里得距离。若有多个满足条件的 $f_i$，输出其中任意一个均可。

### 【输入】

```
$T$
$N$
$x_0$ $y_0$
$x_1$ $y_1$
$\vdots$
$x_{N-1}$ $y_{N-1}$
$\vdots$
```

### 【输出】

对每组数据，按以下格式输出答案。

```
$f_0$ $f_1$ $\ldots$ $f_{N-1}$
```

### 【输入样例】

```
2
4
0 0
4 0
4 3
0 3
5
-3 0
0 -2
4 0
2 3
-1 4
```

### 【输出样例】

```
2 3 0 1
2 4 0 0 2
```

### 【数据范围】

- $1 \leq T \leq 100000$
- $3 \leq N \leq 500000$
- $|x_i|, |y_i| \leq 1000000000$
- 所有输入值均为整数。
- $p_0, p_1, \dots, p_{N-1}$ 是严格凸多边形按逆时针顺序排列的互不相同的顶点。
- 所有数据中 $N$ 的总和不超过 $500000$。
