### 【题目描述】

给定一个长度为 $N$ 的整数序列 $A$。请找出 $A$ 的一个最长上升子序列。

### 【输入】

```
$N$
$A_0$ $A_1$ $\dots$ $A_{N - 1}$
```

### 【输出】

第 1 行输出上升子序列的最大长度 $K$。
第 2 行输出一个长度为 $K$ 的上升子序列。
$i_k$ 是该子序列的第 $k$ 个元素的下标。

```
$K$
$i_0$ $i_1$ $\dots$ $i_{K - 1}$
```

### 【输入样例】

```
5
3 1 4 1 5
```

### 【输出样例】

```
3
1 2 4
```

### 【输入样例2】

```
5
3 3 2 3 1
```

### 【输出样例2】

```
2
2 3
```

### 【数据范围】

- $1 \leq N \leq 500000$
- $0 \leq A_i \leq 1000000000$
