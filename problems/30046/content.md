### 【题目描述】

有一个初始为空的线性函数序列 $f = ()$。请处理 $Q$ 个查询。

- `0 $a$ $b$`：在序列 $f$ 的末尾添加一个线性函数 $\lambda x. ax + b$。
- `1`：删除序列 $f$ 开头的线性函数。
- `2 $x$`：设 $f = (f_{l}, \dots, f_{r - 1})$，输出 $f _ {r - 1}(f _ {r - 2}(\dots (f _ l(x)) \dots)) \bmod 998244353$。如果 $f = ()$，则输出 $x$。

### 【输入】

~~~
$Q$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
~~~

### 【输出】

对每个 `2 $x$` 查询，在一行输出一个整数，表示该查询的答案。

### 【输入样例】

```
6
0 4 5
2 3
0 2 1
2 2
1
2 3
```

### 【输出样例】

```
17
27
7
```

### 【输入样例2】

```
1
2 1333
```

### 【输出样例2】

```
1333
```

### 【数据范围】

- $1 \leq Q \leq 500,000$
- $1 \leq a \lt 998244353$
- $0 \leq b, x \lt 998244353$
- 当查询 $1$ 到来时，序列 $f$ 不为空。
