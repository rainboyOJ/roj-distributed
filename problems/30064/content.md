### 【题目描述】

给定一个长度为 $N$ 的整数序列 $a_0, a_1, \ldots, a_{N-1}$。请按顺序处理以下 $Q$ 个查询：

- $l$ $r$：输出 $a_{l}, a_{l+1}, \ldots, a_{r-1}$ 的一个众数，以及它出现的次数。如果存在多个众数，输出其中任意一个。

### 【输入】

输入格式如下：

```
$N$ $Q$
$a_0$ $a_1$ $\cdots$ $a_{N-1}$
$l_0$ $r_0$
$\vdots$
$l_{Q-1}$ $r_{Q-1}$
```

### 【输出】

对于每个查询，输出一行两个整数，分别表示一个众数及其出现次数。如果存在多个众数，输出其中任意一个。

### 【输入样例】

```
5 3
3 7 1 2 1
1 5
3 4
0 4
```

### 【输出样例】

```
1 2
2 1
3 1
```

### 【数据范围】

- $1 \leq N \leq 100000$
- $0 \leq Q \leq 100000$
- $0 \leq a_i \leq 1000000000$
- $0 \leq l \lt r \leq N$
