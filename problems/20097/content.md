# C. 网络建设

## 题目描述

星际联邦正在构建一套跨星系通信网络。该网络具有以下核心特性：

1. 节点结构：网络由若干个中继站组成，每个中继站要么是终端站（无下级节点），要么是枢纽站（必须连接两个下级中继站）。
2. 层级结构：整个网络具有严格的层级关系。
   - 主控站位于第 $1$ 层（根节点）。
   - 最远的终端站位于第 $k$ 层。
3. 结构要求：网络必须形成完整连通结构，不存在孤立节点。

建设目标：联邦工程师需要计算：当网络包含 $n$ 个中继站且最远终端位于第 $k$ 层时，有多少种不同的网络拓扑结构？由于星系规模庞大，结果需要对星际联邦标准模数 $9901$ 取模。

## 输入格式

输入一行由两个空格分开的整数 $n$，$k$。

## 输出格式

输出一行一个整数表示答案。

## 样例输入1

```
5 3
```

### 样例输出1

```input
2
```

## 样例输入2

```
29 7
```

### 样例输出2

```input
768
```

## 数据范围

- 对于 $10\%$ 的数据，$3 \le n \le 10$，$2 \le k \le 10$。
- 对于 $30\%$ 的数据，$3 \le n \le 30$，$2 \le k \le 10$。
- 对于 $100\%$ 的数据，$3 \le n \le 200$，$2 \le k \le 100$。
