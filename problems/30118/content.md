### 【题目描述】

给定一张 $N$ 个顶点、$M$ 条边的简单无向图。第 $i$ 条边为 $(u_i, v_i)$。

求最大匹配。

### 【输入】

```
$N$ $M$
$u_0$ $v_0$
$u_1$ $v_1$
:
$u_{M - 1}$ $v_{M - 1}$
```

### 【输出】

```
$X$
$a_0$ $b_0$
$a_1$ $b_1$
:
$a_{X - 1}$ $b_{X - 1}$
```

$X$ 为最大匹配的大小。

### 【输入样例】

```
7 8
2 0
0 5
5 6
6 1
1 0
1 3
3 4
1 4
```

### 【输出样例】

```
3
0 2
1 6
3 4
```

### 【输入样例2】

```
5 4
0 1
0 2
0 3
0 4
```

### 【输出样例2】

```
1
0 1
```

### 【数据范围】

- $1 \leq N \leq 500$
- $0 \leq M \leq \frac{N(N-1)}{2}$
- $0 \leq u_i, v_i < N$
