### 【题目描述】

给定一个素数 $p$ 和一个首一多项式

$$
f(x)=\sum_{i=0}^{N} a_i x^i \in \mathbb{F}_p[x].
$$

将 $f(x)$ 分解为首一不可约多项式的乘积。

### 【输入】

```
$N$ $p$
$a_0$ $a_1$ ... $a_N$
```

### 【输出】

输出不同不可约因子的数量 $K$。
对于每个因子 $g_i$，输出其重数 $e_i$、次数 $d_i$ 以及多项式

$$
g_i(x)=\sum_{j=0}^{d_i} b_{i,j}x^j
$$

的系数 $b_{i,0}, b_{i,1}, \ldots, b_{i,d_i}$。

输出必须满足：

- $e_i \geq 1$
- $d_i \geq 1$
- $b_{i,d_i}=1$
- 每个 $g_i(x)$ 在 $\mathbb{F}_p$ 上不可约
- 各个 $g_i(x)$ 两两不同
- $\prod_i g_i(x)^{e_i}=f(x)$

因子的输出顺序可以任意。如果 $f(x)=1$，输出 $K=0$。

```
$K$
$e_1$ $d_1$ $b_{1,0}$ $b_{1,1}$ ... $b_{1,d_1}$
$\vdots$
$e_K$ $d_K$ $b_{K,0}$ $b_{K,1}$ ... $b_{K,d_K}$
```

### 【输入样例】

```
0 998244353
1
```

### 【输出样例】

```
0
```

### 【输入样例2】

```
2 5
2 3 1
```

### 【输出样例2】

```
2
1 1 2 1
1 1 1 1
```

### 【输入样例3】

```
6 2
1 1 1 1 1 1 1
```

### 【输出样例3】

```
2
1 3 1 0 1 1
1 3 1 1 0 1
```

### 【输入样例4】

```
3 7
6 0 0 1
```

### 【输出样例4】

```
3
1 1 3 1
1 1 5 1
1 1 6 1
```

### 【数据范围】

- $2 \leq p \leq 998244353$
- $p$ 是素数。
- $0 \leq N \leq 100$
- $0 \leq a_i < p$
- $a_N=1$
