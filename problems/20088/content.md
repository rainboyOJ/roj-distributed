# C. 能量融合

## 题目描述

在星辰神殿中，有 $n$ 颗魔法宝石排成星环阵列，每颗宝石散发着独特的能量波动，能量波动由一个非负整数表示。

大祭司需要从中选择 $k$ 颗不同的宝石进行能量融合仪式，谐振强度由 $k$ 颗宝石的能量异或和决定。神殿古籍记载：宝石选择方案总数不超过 $10^6$（即组合数 $C_n^k \le 10^6$）。大祭司需要找到最大的谐振强度。

## 输入格式

第一行包含两个整数 $n$，$k$，分别表示宝石数量、选取的宝石数量。

第二行输入 $n$ 个整数 $a_i$，表示宝石的能量波动。

## 输出格式

输出一个整数，表示最大的谐振强度。

## 样例输入1

```
4 2
3 2 6 4
```

## 样例输出1

```
7
```

## 样例解释

选择 $3$ 和 $4$ 能使异或和最大，异或和为 $7$。

## 数据范围

- 对于 $20\%$ 的数据，$2 \le k \le n \le 10$，$1 \le a_i \le 2^{30}$，$C_n^k \le 10^6$。
- 对于 $100\%$ 的数据，$2 \le k \le n \le 2 \times 10^5$，$1 \le a_i \le 2^{60}$，$C_n^k \le 10^6$。
