### 【题目描述】

给定整数序列 $a_0, a_1, ..., a_{N - 1}$ 和 $b_0, b_1, ..., b_{M - 1}$。这里 $a$ 与 $b$ 都是凸的。计算按下式定义的整数序列 $c_0, c_1, ..., c_{(N - 1) + (M - 1)}$：

$$c_k = \min_{i+j=k} (a_i+b_j)$$

### 【输入】

```
$N$ $M$
$a_0$ $a_1$ ... $a_{N-1}$
$b_0$ $b_1$ ... $b_{M-1}$
```

### 【输出】

```
$c_0$ $c_1$ ... $c_{(N - 1) + (M - 1)}$
```

### 【输入样例】

```
4 5
3 1 0 3
5 2 1 1 4
```

### 【输出样例】

```
8 5 3 2 1 1 4 7
```

### 【数据范围】

- $1 \leq N, M \leq 524288$
- $0 \leq a_i, b_i \leq 10^9$
- $a$ 是凸的，即对 $0 \leq i < N - 2$ 有 $a_{i+1}-a_i \leq a_{i+2}-a_{i+1}$。
- $b$ 是凸的，即对 $0 \leq i < M - 2$ 有 $b_{i+1}-b_i \leq b_{i+2}-b_{i+1}$。
