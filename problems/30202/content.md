### 【题目描述】

给定多项式 $f(x) = \sum_{i = 0}^{N - 1} c_i x^i\in \mathbb{Z}[x]$ 以及整数 $M, a, r$。
对于每个 $0\leq i < M$，输出 $f(ar^i) \bmod 998244353$。

### 【输入】

```
$N$ $M$ $a$ $r$
$c_0$ $c_1$ ... $c_{N-1}$
```

### 【输出】

```
$f(ar^0)$ $f(ar^1)$ ... $f(ar^{M-1})$
```

### 【输入样例】

```
5 4 3 2
1 2 3 4 5
```

### 【输出样例】

```
547 7465 111049 1715953
```

### 【输入样例2】

```
3 4 2 0
3 2 0
```

### 【输出样例2】

```
7 3 3 3
```

### 【数据范围】

- $1 \leq N, M \leq 524288$
- $0 \leq a, r < 998244353$
