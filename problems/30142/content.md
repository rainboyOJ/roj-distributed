### 【题目描述】

给定一个 $N \times N$ 矩阵 $M = \lbrace a_{ij} \rbrace$ 和一个整数 $m$。输出 $\mathrm{det}(M) \bmod m$。

### 【输入】

输入格式如下：

```
$N$ $m$
$a_{11}$ $a_{12}$ ... $a_{1N}$
$a_{21}$ $a_{22}$ ... $a_{2N}$
:
$a_{N1}$ $a_{N2}$ ... $a_{NN}$
```

### 【输出】

输出 $\mathrm{det}(M) \bmod m$。

### 【输入样例】

```
0 998244353
```

### 【输出样例】

```
1
```

### 【输入样例2】

```
2 2
0 1
1 0
```

### 【输出样例2】

```
1
```

### 【输入样例3】

```
3 10
1 2 3
4 5 6
7 8 9
```

### 【输出样例3】

```
0
```

### 【数据范围】

- $0 \leq N \leq 500$
- $1 \lt m \leq 1000000000$
- $0 \leq a_{ij} < m$
