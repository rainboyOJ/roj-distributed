### 【题目描述】

给定一个长度为 $N$ 的线性函数序列 $f_0, f_1, ..., f_{N-1}$。初始时，对于所有 $i$，有 $f_i(x)=x$。依次处理 $Q$ 个查询：

- `0 $p$ $c$ $d`：令 $f_p \gets cx + d$。
- `1 $l$ $r$ $x$`：输出 $f_{r-1}(f_{r-2}(...f_l(x))) \bmod 998244353$。

### 【输入】

```
$N$ $Q$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
```

### 【输出】

对于每个类型为 `1` 的查询，输出一行其计算结果。

### 【输入样例】

```
1000000000 6
0 100 2 3
0 10000 4 5
1 99 100 10
1 1 1000000000 1
0 1000000 6 7
1 1 1000000000 1
```

### 【输出样例】

```
10
25
157
```

### 【数据范围】

- $1 \leq N \leq 1000000000$
- $1 \leq Q \leq 500000$
- $1 \leq c < 998244353$
- $0 \leq d, x < 998244353$
- $0 \leq p < N$
- $0 \leq l < r \leq N$
