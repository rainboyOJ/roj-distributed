### 【题目描述】

给定整数序列 $a_0, a_1, ..., a_{N - 1}$ 与 $b_0, b_1, ..., b_{M - 1}$。其中 $a$ 是凸的。请计算如下定义的整数序列 $c_0, c_1, ..., c_{(N - 1) + (M - 1)}$：

$$c_k = \min_{i+j=k} (a_i+b_j)$$

### 【输入】

```
$N$ $M$
$a_0$ $a_1$ ... $a_{N-1}$
$b_0$ $b_1$ ... $b_{M-1}$
```

### 【输出】

```
$c_0$ $c_1$ ... $c_{(N - 1) + (M - 1)}$
```

### 【输入样例】

```
4 5
3 1 0 3
5 1 3 3 2
```

### 【输出样例】

```
8 4 2 1 3 3 2 5
```

### 【数据范围】

- $1 \leq N, M \leq 524288$
- $0 \leq a_i, b_i \leq 10^9$
- $a$ 是凸的，即对 $0 \leq i < N - 2$ 有 $a_{i+1}-a_i\leq a_{i+2}-a_{i+1}$。
