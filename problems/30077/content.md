### 【题目描述】

给定一个长度为 $N$ 的整数序列 $A$。求 $A$ 的本质不同子序列的个数，对 $998244353$ 取模。

### 【输入】

```
$N$
$A_0$ $A_1$ $\dots$ $A_{N - 1}$
```

### 【输出】

输出一行，表示本质不同子序列的个数对 $998244353$ 取模的结果。

### 【输入样例】

```
5
0 0 0 1 1
```

### 【输出样例】

```
11
```

### 【输入样例2】

```
9
9 9 8 2 4 4 3 5 3
```

### 【输出样例2】

```
251
```

### 【数据范围】

- $1 \leq N \leq 500000$
- $0 \leq A_i \leq 1000000000$
