### 【题目描述】

给定一个长度为 $N$ 的非负整数序列 $A = (a_0, a_1, \ldots, a_{N-1})$。依次处理以下 $Q$ 个查询：

- 给定整数 $l_i$ 和 $r_i$，输出 $\sum_{k=l_i}^{r_i-1} a_k$。

### 【输入】

```
$N$ $Q$
$a_0$ $a_1$ $\ldots$ $a_{N-1}$
$l_1$ $r_1$
$\vdots$
$l_Q$ $r_Q$
```

### 【输出】

对每个查询输出一行一个整数，表示 $\sum_{k=l_i}^{r_i-1} a_k$。

### 【输入样例】

```
5 5
1 10 100 1000 10000
2 3
0 3
2 5
3 4
0 5
```

### 【输出样例】

```
100
111
11100
1000
11111
```

### 【数据范围】

- $1 \leq N \leq 500000$
- $1 \leq Q \leq 500000$
- $0 \leq a_i \leq 1000000000$
- $0 \leq l_i < r_i \leq N$
