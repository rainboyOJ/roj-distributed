### 【题目描述】

给定形式幂级数 $f(x) = \sum_{i=0}^{N-1} a_i x^i \in \mathbb{F}\_{998244353}[[x]]$。
计算 $f(x)$ 的平方根的前 $N$ 项。
换句话说，求 $g(x) = \sum_{i=0}^{N-1} b_i x^i \in \mathbb{F}\_{998244353}[[x]]$，使得

$$f(x) \equiv g(x)^2 \pmod{x^N}。$$

### 【输入】

```
$N$
$a_0$ $a_1$ $\cdots$ $a_{N - 1}$
```

### 【输出】

如果不存在满足条件的 $g(x)$，输出

```
-1
```

否则，任选一个满足条件的 $g(x)$，输出

```
$b_0$ $b_1$ $\cdots$ $b_{N - 1}$
```

### 【输入样例】

```
4
0 0 9 12
```

### 【输出样例】

```
0 3 2 332748117
```

### 【输入样例2】

```
4
0 0 10 12
```

### 【输出样例2】

```
-1
```

### 【数据范围】

- $1 \leq N \leq 500000$
- $0 \leq a_i < 998244353$
