# MX主义 (mxism)

## 题目描述

MX掏出了一个祖传字符串，据说是对这个字符串进行解密就可以得到MX主义的真经。

具体的，给定一个字符串 $S$。求对字符串 $S$ 进行零次或多次以下操作后，能得到的字符串的最小长度。

- 选择一个连续出现的 `mx` 和一个介于 $[0, K]$ 的整数  $i$。接着，你可以删除 `mx` 以及后面的 $i$ 个字符。

## 输入格式

- 第一行一个字符串 $S$
- 第二行一个正整数 $K$

## 输出格式

- 一行一个整数，表示答案

## 样例

### 样例输入 1

```
mxmxhmooosx
3
```

### 样例输出 1

```
1
```

### 样例输入 2

```
mxglmxrdafdsadxmyfdsfdx
4
```

### 样例输出 2
```
11
```

### 数据范围与约定

| 测试点编号  | 特殊性质                            |
| ----------- | ----------------------------------- |
| $1 \sim 3$  | $2 \leq \lvert S \rvert \leq 10$                |
| $4 \sim 5$  | 保证 $S$ 中只有一个连续出现的  `mx` |
| $6 \sim 10$ | 无                                  |

对于 $100\%$ 的数据，满足：

- $0 \leq K < |S| \leq 300$
- $S$ 仅包含小写字母
