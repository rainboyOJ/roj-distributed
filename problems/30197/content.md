### 【题目描述】

给定一个形式幂级数 $f(x) = \sum_{i=0}^{N-1} a_i x^i \in \mathbb{F}\_{998244353}[[x]]$，其中 $a_0 \ne 0$。
$f$ 中只有 $K$ 个系数非零，输入只给出这些系数 $a_{i_k}$。

求 $\frac{1}{f(x)} = \sum_{i=0}^{\infty} b_i x^i$ 的前 $N$ 项。
也就是说，求出 $g(x) = \sum_{i=0}^{N-1} b_i x^i \in \mathbb{F}\_{998244353}[[x]]$ 使得

$$f(x) g(x) \equiv 1 \pmod{x^N}.$$

### 【输入】

```
$N$ $K$
$i_0$ $a_{i_0}$
$\vdots$
$i_{K-1}$ $a_{i_{K-1}}$
```

### 【输出】

```
$b_0$ $b_1$ $\cdots$ $b_{N - 1}$
```

### 【输入样例】

```
5 2
0 1
2 1
```

### 【输出样例】

```
1 0 998244352 0 1
```

### 【输入样例2】

```
10 5
0 5
1 4
2 3
3 2
4 1
```

### 【输出样例2】

```
598946612 718735934 862483121 635682004 163871793 995241634 275905156 386987871 291888821 422779055
```

### 【数据范围】

- $1 \leq N \leq 1000000$
- $1 \leq K \leq 10$
- $0 = i_0 < \cdots < i_{K-1} \leq N - 1$
- $1 \leq a_{i_k} < 998244353$
