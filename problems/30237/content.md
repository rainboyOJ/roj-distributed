### 【题目描述】

给定一棵 $N$ 个顶点的树，其边为 $(u_i, v_i)$。第 $i$ 个顶点上写有一个值 $a_i$。

请处理 $Q$ 次查询。保证每次查询后该图仍然是一棵树。

- `0 $u$ $v$ $w$ $x$`：删除边 $(u, v)$，并添加边 $(w, x)$。
- `1 $p$ $x$`：$a_p \gets a_p + x$
- `2 $v$ $p$`：对于边 $(v, p)$（把 $p$ 视为父亲），输出 $v$ 的子树中所有顶点的权值之和。

### 【输入】

```
$N$ $Q$
$a_0$ $a_1$ ... $a_{N - 1}$
$u_0$ $v_0$
$u_1$ $v_1$
:
$u_{N - 2}$ $v_{N - 2}$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
```

### 【输出】

对每个 `2 $v$ $p$` 查询，输出一行一个整数，表示把 $p$ 视为父亲时 $v$ 的子树中所有顶点的权值之和。

### 【输入样例】

```
5 7
1 10 100 1000 10000
0 1
1 2
2 3
1 4
2 1 2
1 1 100000
2 1 2
0 1 2 2 0
2 0 2
0 2 3 3 1
2 1 4
```

### 【输出样例】

```
10011
110011
110011
101111
```

### 【数据范围】

- $1 \leq N, Q \leq 200,000$
- $0 \leq a_i, x \leq 10^9$
- $0 \leq p, u_i, v_i < N$
- $(u_i, v_i)$ 构成的是一棵树
