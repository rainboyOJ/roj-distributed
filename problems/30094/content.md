### 【题目描述】

给定平面上的 $N$ 个点 $p_i(x_i, y_i)$（$0\leq i\leq N - 1$）。

设 $C$ 为这 $N$ 个点的最小覆盖圆。

对每个 $i = 0, 1, \dots, N-1$，判断 $p_i$ 是否位于 $C$ 的圆周（边界）上。

### 【输入】

```
$N$
$x_0$ $y_0$
$x_1$ $y_1$
:
$x_{N - 1}$ $y_{N - 1}$
```

### 【输出】

```
$T$
```

输出一个长度为 $N$ 的 0/1 串 $T$。

对每个 $i = 0, 1, \dots, N-1$，若 $p_i$ 位于 $C$ 的圆周上，则令 $T[i] = 1$；否则令 $T[i] = 0$。

### 【输入样例】

```
8
-1 1
0 0
0 -1
1 3
1 -2
2 0
3 2
4 1
```

### 【输出样例】

```
10011001
```

### 【数据范围】

- $2 \leq N \leq 100000$
- $|x_i|, |y_i| \leq 10000$
- $N$ 个点两两不同。
- 输入中的所有值均为整数。
