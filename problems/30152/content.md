### 【题目描述】

给定一个 $N \times M$ 的矩阵 $A$，以及一个大小为 $N$ 的向量 $b$。请计算一个大小为 $M$ 的向量 $x$，使得 $Ax=b$。所有运算均在 $\mathbb{F}_{2}$ 中进行。

对于矩阵和向量的输入与输出，请将每一行视为由其分量（$0$ 或 $1$）拼接而成的字符串。

### 【输入】

第一行包含两个整数 $N$ 和 $M$。

接下来 $N$ 行，每行包含一个字符串

```
$A_{i,0}A_{i,1}\cdots A_{i,M-1}$
```

表示矩阵 $A$ 的第 $i$ 行。

最后一行包含一个字符串

```
$b_0b_1\cdots b_{N-1}$
```

表示向量 $b$。

### 【输出】

如果无解，输出

```
-1
```

否则按以下格式输出：

```
$R$
$c_0c_1\cdots c_{M-1}$
$d_{0,0}d_{0,1}\cdots d_{0,M-1}$
$\vdots$
$d_{R-1,0}d_{R-1,1}\cdots d_{R-1,M-1}$
```

其中，$R$ 是解空间的秩。$c_i$ 是一个解。对于每个 $j$，$d_{j,0}\cdots d_{j,M-1}$ 是解空间的一个基。

### 【输入样例】

```
3 3
101
011
110
011
```

### 【输出样例】

```
1
010
111
```

### 【输入样例2】

```
3 3
101
011
110
111
```

### 【输出样例2】

```
-1
```

### 【输入样例3】

```
1 3
111
1
```

### 【输出样例3】

```
2
100
110
101
```

### 【数据范围】

- $1 \leq N \leq 4096$
- $1 \leq M \leq 4096$
- $A_{ij} \in \lbrace 0,1\rbrace$
- $b_i \in \lbrace 0,1\rbrace$
