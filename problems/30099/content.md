### 【题目描述】

给定一个有 $L + R$ 个顶点、$M$ 条边的无向二分图。第 $i$ 条边为 $(a_i, b_i)$。

请计算一个达到边色数的合法边染色方案。

### 【输入】

第一行包含三个整数 $L$、$R$、$M$。

接下来 $M$ 行，每行包含两个整数 $a_i$、$b_i$，表示第 $i$ 条边连接左侧顶点 $a_i$ 和右侧顶点 $b_i$。

```text
$L$ $R$ $M$
$a_0$ $b_0$
$a_1$ $b_1$
$\vdots$
$a_{M - 1}$ $b_{M - 1}$
```

### 【输出】

第一行输出 $K$。

接下来 $M$ 行，第 $i$ 行输出整数 $c_i$。

$K$ 是边色数，$c_i$ 是表示第 $i$ 条边颜色的整数。$c_i$ 应满足 $0 \leq c_i < K$。

```text
$K$
$c_0$
$c_1$
$\vdots$
$c_{M - 1}$
```

### 【输入样例】

```
4 4 7
1 1
2 2
0 0
3 1
1 2
2 0
3 2
```

### 【输出样例】

```
3
0
2
1
2
1
0
0
```

### 【数据范围】

- $1 \leq L, R \leq 100000$
- $1 \leq M \leq  100000$
- $0 \leq a_i < L$
- $0 \leq b_i < R$
