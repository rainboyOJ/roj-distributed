### 【题目描述】

给定整数序列 $a_0, a_1, ..., a_{2^N - 1}$ 和 $b_0, b_1, ..., b_{2^N - 1}$。按如下方式计算整数序列 $c_0, c_1, ..., c_{2^N - 1}$：

$$c_k = \sum_{i \times j \equiv k \pmod{2^N}} a_i b_j \bmod 998244353$$

### 【输入】

```
$N$
$a_0$ $a_1$ ... $a_{2^N - 1}$
$b_0$ $b_1$ ... $b_{2^N - 1}$
```

### 【输出】

```
$c_0$ $c_1$ ... $c_{2^N - 1}$
```

### 【输入样例】

```
2
3 1 4 1
5 9 2 6
```

### 【输出样例】

```
104 15 64 15
```

### 【输入样例2】

```
0
998244352
998244352
```

### 【输出样例2】

```
1
```

### 【数据范围】

- $0 \leq N \leq 20$
- $0 \leq a_i, b_i < 998244353$
