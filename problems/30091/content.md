### 【题目描述】

给定 $N$ 个二维平面上的点，第 $i$ 个点为 $(x_i, y_i)$。

对每一对 $i, j$，在两点之间连一条边，边权为 $\sqrt{(x_i - x_j)^2 + (y_i - y_j)^2}$。

求这个图的一棵最小生成树。

### 【输入】

```
$N$
$x_0$ $y_0$
$x_1$ $y_1$
:
$x_{N-1}$ $y_{N-1}$
```

### 【输出】

```
$u_0$ $v_0$
$u_1$ $v_1$
:
$u_{N-2}$ $v_{N-2}$
```

输出这 $N-1$ 对 $u_i, v_i$，表示最小生成树中各条边两端点的点的下标。

若有多解，输出任意一组即可。

### 【输入样例】

```
5
-1 -1
-6 4
-9 -7
2 5
-7 6
```

### 【输出样例】

```
0 1
0 2
0 3
1 4
```

### 【数据范围】

- $1 \leq N \leq 200000$
- $|x_i|, |y_i| \leq 10000$
