### 【题目描述】

本题有 $T$ 组测试数据。
给定一个非负整数 $A$ 和一个正整数 $B$，输出满足下列式子的整数 $q, r$：

- $q = \left \lfloor \frac{A}{B} \right \rfloor$
- $A = qB + r$

### 【输入】

```
$T$
$A$ $B$
 $\vdots$
$A$ $B$
```

### 【输出】

```
$q$ $r$
 $\vdots$
$q$ $r$
```

### 【输入样例】

```
6
47 10
50 10
3 10
0 10
100000000000000000000 9999999999
10000000000000000000000000000000000000000 99999999999999999999
```

### 【输出样例】

```
4 7
5 0
0 3
0 0
10000000001 1
100000000000000000001 1
```

### 【数据范围】

- $1 \leq T \leq 2000000$
- $0 \leq A \leq 10^{2000000}$
- $1 \leq B \leq 10^{2000000}$
- 所有测试数据中（$A$ 的字符数）$+$（$B$ 的字符数）之和不超过 $4000002$。
