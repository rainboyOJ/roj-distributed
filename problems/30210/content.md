### 【题目描述】

给定 $N$ 个多项式 $f_i(x) = \sum_{j=0}^{d_j} a_{i,j} x^{j} \in \mathbb{Z}[x]$（$i=0,\ldots,N-1$）。
求 $f(x) = \prod_{i=0}^{N-1} f_i(x)$ 在模 $998244353$ 下的结果。

### 【输入】

```
$N$
$d_0$ $a_{0,0}$ $\ldots$ $a_{0,d_0}$
$\vdots$
$d_{N-1}$ $a_{N-1,0}$ $\ldots$ $a_{N-1,d_{N-1}}$
```

### 【输出】

```
$a_0$ $a_1$ ... $a_{D}$
```

其中 $D = \sum_{i=0}^{N-1} d_i$，且 $f(x) = \sum_{j=0}^{D} a_jx^j \pmod{998244353}$。

### 【输入样例】

```
3
0 2
1 1 2
2 3 2 1
```

### 【输出样例】

```
6 16 10 4
```

$f(x) = 2(1+2x)(3+2x+x^2) = 6+16x+10x^2+4x^3$。

### 【输入样例2】

```
1
2 3 4 5
```

### 【输出样例2】

```
3 4 5
```

### 【输入样例3】

```
0
```

### 【输出样例3】

```
1
```

### 【数据范围】

- $0 \leq N \leq 500000$
- $0 \leq d_{i}$ 且 $\sum_{i=0}^{N-1} d_i \leq 500000$
- $0 \leq a_{i,j} < 998244353$
- $a_{i, d_i}\neq 0$
