# 环

题目描述
小 L 生活在一个王国。

这个王国有 𝑛𝑛 个城市， 𝑚𝑚 条单向道路。

小 L 有一个神奇的计数器，初始是 0，每经过一条边，这个计数器就会加一，但是
计数器到 3 的时候就会变为 0，也就是说，计数器是 2 时再经过一条边，计数器会
变成 0。

求有多少个点，可以在经过若干条边后回到起点，并且计数器变为 1。（可以经过
一条边多次）

输入格式
第一行两个整数𝑛𝑛, 𝑚𝑚。

接下来𝑚𝑚行，每行两个整数，表示一条有向边。

输出格式
输出一行一个整数表示答案。

样例输入 1
2 2
1 2
2 1

样例输出 1
2

样例输入 2
3 3
1 2
2 3
3 1

样例输出 2
0

样例输入输出 3
见下发文件。

数据规模
共 10 个测试点。
测试点1,2满足𝑛𝑛 ≤ 10, 𝑚𝑚 ≤ 15。

测试点3,4,5满足𝑛𝑛 ≤ 1000, 𝑚𝑚 ≤ 2000。

测试点6,7,8满足将有向边视为无向边，并消去重边以后，图是一棵树。

对于所有数据满足𝑛𝑛 ≤ 200000, 𝑚𝑚 ≤ 400000。
