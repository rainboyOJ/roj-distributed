### 【题目描述】

给定整数序列 $a_1, ..., a_{N}$ 和 $b_1, ..., b_{N}$。按如下方式计算整数序列 $c_1, ..., c_{N}$：

$$c_k = \sum_{\gcd(i,j)=k} a_ib_j \bmod 998244353$$

### 【输入】

```
$N$
$a_1$ ... $a_{N}$
$b_1$ ... $b_{N}$
```

### 【输出】

```
$c_1$ ... $c_{N}$
```

### 【输入样例】

```
6
1 2 3 4 5 6
6 5 4 3 2 1
```

### 【输出样例】

```
284 90 39 12 10 6
```

### 【数据范围】

- $1 \leq N \leq 1000000$
- $0 \leq a_i, b_i < 998244353$
