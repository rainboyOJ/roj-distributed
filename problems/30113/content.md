### 【题目描述】

给定一个有 $N$ 个顶点的空图。第 $i$ 个顶点上写有一个值 $a_i$。

依次处理 $Q$ 个查询：

- `0 $u$ $v$`：在顶点 $u$ 和顶点 $v$ 之间添加一条边。（保证在此查询之前，顶点 $u$ 和顶点 $v$ 之间没有边。）
- `1 $u$ $v$`：删除顶点 $u$ 和顶点 $v$ 之间的边。（保证在此查询之前，顶点 $u$ 和顶点 $v$ 之间有边。）
- `2 $v$ $x$`：令 $a_v \gets a_v + x$。
- `3 $v$`：输出所有能通过路径与顶点 $v$ 连通的顶点上的值之和。

### 【输入】

```
$N$ $Q$
$a_0$ $a_1$ ... $a_{N - 1}$
$\textrm{Query}_0$
$\textrm{Query}_1$
:
$\textrm{Query}_{Q - 1}$
```

### 【输出】

对于每个 `3 $v$` 查询，输出一行一个整数，表示所有能通过路径与顶点 $v$ 连通的顶点上的值之和。

### 【输入样例】

```
5 16
1 10 100 1000 10000
0 0 1
0 1 2
0 2 3
0 3 4
0 0 4
3 3
1 1 2
3 1
1 3 4
3 0
2 1 100000
3 1
0 1 4
3 2
0 3 4
3 0
```

### 【输出样例】

```
11111
11111
10011
110011
1100
111111
```

### 【数据范围】

- $1 \leq N, Q \leq 300000$
- $0 \leq a_i, x \leq 1000000000$
- $0 \leq u_i, v_i < N$
- $u_i \neq v_i$
