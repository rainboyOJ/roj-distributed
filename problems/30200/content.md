### 【题目描述】

给定一个形式幂级数 $f(x) = \sum_{i=0}^{N-1} a_i x^i \in \mathbb{Q}[[x]]$，其中 $a_0 = 1$。
$f$ 只有 $K$ 个系数非零，输入只给出这些系数 $a_{i_k}$。

求 $\log(f(x)) = \sum_{i=0}^{\infty} b_i x^i$ 的前 $N$ 项。
也就是说，求 $g(x) = \sum_{i=0}^{N-1} b_i x^i \in \mathbb{Q}[[x]]$，使得 $b_0 = 0$ 且

$$f(x) \equiv \sum_{k=0}^{N-1} \frac{g(x)^k}{k!} \pmod{x^N}.$$

将系数对 $998244353$ 取模后输出。

### 【输入】

```
$N$ $K$
$i_0$ $a_{i_0}$
$\vdots$
$i_{K-1}$ $a_{i_{K-1}}$
```

### 【输出】

```
$b_0$ $b_1$ $\cdots$ $b_{N - 1}$
```

### 【输入样例】

```
5 2
0 1
2 1
```

### 【输出样例】

```
0 0 1 0 499122176
```

### 【输入样例2】

```
10 5
0 1
1 1
2 499122179
3 166374064
4 291154613
```

### 【输出样例2】

```
0 1 2 3 4 307791995 131712787 793247753 831003798 590204334
```

### 【数据范围】

- $1 \leq N \leq 1000000$
- $1 \leq K \leq 10$
- $0 = i_0 < \cdots < i_{K-1} \leq N - 1$
- $1 \leq a_{i_k} < 998244353$
- $a_0 = 1$
