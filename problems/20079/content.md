### 题目描述

小 A 手上有两个数 $A$ 和 $B$ ，满足 $A\geq B$ ，且它们长度一样，可能有前导零。现在他需要选择 $A$ 的恰好 $k$ 位，任意修改它们，使得 $A<B$ 。他想知道修改后 $A$ 的最大值是多少。

### 输入格式

第一行一个整数 $T$ 表示测试数据组数。    

接下来 $T$ 行两个字符串 $A,B$ 和一个整数 $k$ ，表示两个数和修改位数。

### 输出格式

$T$ 行，每行一个字符串，表示修改后最大的 $A$ ，字符串长度必须和原来的 $A$ 长度相等，可以有前导零。

特别地，如果无论怎么修改都不能使 $A<B$ ，输出 $-1$。

### 数据范围

假设这里的 $n$ 为 $A,B$ 的长度：

对于 20% 的数据：$1 \le n \le 5$。

对于 50% 的数据：$1 \le n \le 5000$。

对于另外 20% 的数据：$1 \le n \le 10^5$，$k=1$。

对于 $100\%$ 的数据，$1 \le T \le 100$，$1 \le k \le n \le 10^5$，$A \ge B$。

#### 输入样例1

```

```

#### 输出样例1

```

```
