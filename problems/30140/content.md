### 【题目描述】

给定一个 $N \times N$ 的矩阵 $A = \lbrace a_{ij} \rbrace$，其中每个元素都属于 $\mathbb{Z}/2\mathbb{Z}$，请输出 $A^{-1} = \lbrace b_{ij} \rbrace$。如果逆矩阵不存在，请输出 `-1`。

处理矩阵的输入和输出时，请将每一行视为由其各个分量（`0` 或 `1`）拼接而成的字符串。

### 【输入】

```
$N$
$a _ {11} \cdots a _ {1N}$
$\vdots$
$a _ {N1} \cdots a _ {NN}$
```

### 【输出】

如果不存在满足条件的逆矩阵，请输出

```
-1
```

如果这样的矩阵存在，请输出

```
$b _ {11} \cdots b _ {1N}$
$\vdots$
$b _ {N1} \cdots b _ {NN}$
```

### 【输入样例】

```
3
110
100
011
```

### 【输出样例】

```
010
110
111
```

### 【输入样例2】

```
1
1
```

### 【输出样例2】

```
1
```

### 【输入样例3】

```
1
0
```

### 【输出样例3】

```
-1
```

### 【数据范围】

- $1 \leq N \leq 4096$
- $0 \leq a_{ij} < 2$
